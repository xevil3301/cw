# 白话速查表

> **这一页是给不读长文的人用的。**
> 36 篇压成一张表，每条只回答三件事：**做什么、为什么、要看哪篇。**
> 想听故事、要出处、要案例，再翻对应篇目。

## 二、二十一条方法（一句话版）

| # | 方法 | 为什么管用 |
|---|---|---|
| 00 | 先分清哪些话能信、哪些只是听说 | 来源不明的判断，错一次就够毁掉全盘 |
| 01 | 算“谁更需要谁”，不算“谁更强” | 权力是依赖差，不是实力差 |
| 02 | 想让人点头，用七种理由之一：互惠、承诺、从众、喜欢、权威、稀缺、同类 | 人被机制推着走，不被人品推着走 |
| 03 | 分清“影响”和“操控”：说穿了还成立的是影响 | 见光死的招只能用一次 |
| 04 | 先算最坏那一步，能扛再动手 | 平均值会骗你，最坏值不会 |
| 05 | 控制他看到什么、按什么顺序看到 | 同一件事，顺序一换，结论就变 |
| 06 | 组织里打的不是对错，是位置、预算、地盘、接班 | 认错战场，怎么打都输 |
| 07 | 谈判先定“谈崩了我还有什么” | 有退路的人才有定价权 |
| 08 | 被拿捏的七个信号，命中三个就先停 | 压力下不做决定，是最便宜的自保 |
| 09 | 老办法能用，但要先问“当年的前提现在还在吗” | 环境变了，招就废了 |
| 10 | 每次出手前算五笔账：名声、能不能撤回、法律、报复、还要合作几次 | 赢了这一局输了后面所有局，是净亏 |
| 11 | 找例子别找“他很厉害”，要找“他当时什么条件” | 案例的价值在成立条件，不在戏剧性 |
| 12 | 手段分五级：信息差、锚定框架、恩情羞耻、反打、公开锁定 | 越狠的越脆，越像正常做事的越耐用 |
| 13 | 先算自己六项：位置、本事、关系、时间、名声、退路 | 高估自己手里的牌，是最常见的死法 |
| 14 | 别猜他是什么人，设计一个小场景看他怎么反应 | 一次试探胜过十次观察 |
| 15 | 人分三种：能长期处的、只能按次换的、只会消耗你的 | 用错方式，关系提前烧光 |
| 16 | 防守靠结构不靠警觉；输了先止血再定性 | 警觉会在压力下失效，结构不会 |
| 17 | 别骗他去错的地方，让他自己在对的地方做出你要的选择 | 骗见光死，局见光还成立 |
| 18 | 最有用的消息来自他自己人；最值钱的是“他以为你在干什么” | 反间成本最低，效果最好 |
| 19 | 不要造假东西，只调时间、顺序、归属、语境 | 每条都真，才查不出假 |
| 20 | 别说服他，给他材料让他自己得出“我赚了” | 自己得出的结论，他会拿命维护 |
| 21 | 别在对方给的框架里选，把框架换掉 | 谁定义选项，谁决定结果 |
| 22 | 冲突时先找第三条路，再排序 | 两个选项都难受，说明你还在别人的框架里 |

## 二点五、上围栏四句（对方给你设框架时用）

```text
① "先确认一下，你要的是 A，还是 B？"      → 拆他的单一议题
② "这两个之外，还有第三种做法吗？"          → 直接把框架打开
③ "我们按什么标准判断这件事成不成？"        → 把标准拿过来
④ "这个决定还有谁需要知道？"                → 引入第三方
```

**四句全是问句，没有一句否定。** 问出来是商量，说出来是叫板。

**三条别用**：对方有绝对权力、时间只有一轮、你手上没筹码。

## 四、六个最常被问的问题

**问：我老实，是不是就没法用这套？**
不是。这套里最耐用的部分（结构手段、留痕、设标准、退出）**恰恰是老实人天生擅长的**。你缺的不是狠劲，是“说一句这个不行”的能力。

**问：我该用多狠的？**
先试最轻的。**能一句话解决的事，不要用三步。**

**问：怎么判断一个人值不值得交？**
只看两件事：你出事时他在不在，你帮过他之后他还不还。这两项有一个是零，别的都不用看了。

**问：我被欺负了，想让他付出代价。**
先别。**为了让他难受而做的决定，几乎都会伤到你自己。** 先止损，等你不想报复了，再决定要不要还手。

**问：我是不是想多了？**
用七信号打分。0–3 分就是正常博弈，别往操控上想。**把所有试探当恶意，是老实人最常犯的错。**

**问：这套东西会不会把我变成另一个人？**
会——如果你用它来看所有人。**用它来防人，不会；用它来评估每一个人，会。**

## 五、一句话总结

**先算自己，再摸对方，然后选最轻的那一手。**

其余的，都是细节。
