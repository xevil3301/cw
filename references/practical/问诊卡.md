# 问诊卡

## 用法

**用户一开口，不许直接给方案——除了一种例外。**

**例外：他说"今天就得定"/"现在怎么办"。** 这时先给一个动作（L0 或行为卡），再补问诊。

**为什么**：最急的人拿到三个问题，等于没帮忙。他不会回答，他会去找别人。

**跳过问诊的代价**：你给的方案，是按你以为的诉求做的。

---

## 卡 1 · 三问（必须问完）

```text
第一问：你最想要的结果是什么？具体到"什么状态算成了"。
  追问：是回到原来的样子，还是拿到某个东西，还是让他付出代价？

第二问：你能接受的最大代价是什么？（钱／位置／关系／时间）
  追问：如果最后没解决，你损失得起吗？

第三问：如果这事没解决，你怎么办？
  追问：你有没有别的选择？除了这一条路。
```

**第二问决定手段上限**：能承受大代价 → 可用重手；承受不起 → 只能结构手段。
**第三问答"没想过" → 他没有退路，此时任何进攻都是赌，先帮他造退路。**

---

## 卡 2 · 听三个词，判诉求

| 他说 | 诉求 | 对应打法 |
|---|---|---|
| "我本来应该……"／"我原来……" | **复位** | 五力法 + 向上管理 |
| "不能就这么算了"／"总得有个说法" | **补偿**／**面子** | 谈判 + 合规施压 |
| "我要让他……"／"他也得尝尝" | **报复** | 摊开代价 + 给替代路径 |
| "我怕……"／"万一他……" | **安全** | 补救系统 |

**他反复说的那一句，就是真诉求。**

---

## 卡 3 · 三类诉求，三条路

### 正当（复位、安全）

```text
直接给路径：
· 你要回到什么状态（具体）
· 谁有权决定
· 你缺什么（依据／支持者／时机）
· 第一步做什么（本周）
```

### 灰色（补偿、面子）

```text
给谈判框架 + 拉回合规区：
· 你要的这个数，依据是什么
· 对方能接受的区间大概在哪
· 怎么开口（给话术）
· 什么事不能做（提要求换"不说"＝敲诈）
```

### 危险（报复、用证据换利益）

**不劝，只算三笔账：**

```text
一、你手上的东西够不够（不完整的证据用出去会反伤）
二、一开口要条件，性质就从"他违规"变成"你敲诈"
三、你输得起吗（房贷、孩子、履历）
```

**然后给一条不会把自己搭进去的路**（见卡 4）。

---

## 卡 4 · 合规施压：让他自己算

**分界线只有一条：你有没有提出要求。**

```text
✗ "你把位置还给我，我就不说"   → 敲诈
✓ "我手上有这些东西"（不附条件） → 合法
✓ 让第三方知道你有              → 合法
✓ 把东西放在他能看到的地方        → 合法
```

### 三种安全做法

**一、让第三方知道**

> 不说给谁听，但让人知道"我手上有东西"。

**二 · 在无关场合提一句**

> "这些材料我留着也没用，哪天清理电脑就删了。"

**没有要求，但传递三件事**：我有、我知道你知道、我暂时不用。

**三 · 让它"偶然可见"**

不主动展示，但放在他能看到的地方。**人对自己发现的东西，比被告知的更当真。**

**为什么这样有效**：压力不来自你的要求，来自他的计算。**他没法定你的罪，因为他找不到你的要求。**

## 卡 5 · 问完之后的判断树

```text
诉求类型
 ├─ 正当 → 五力法 / 谈判
 ├─ 灰色 → 谈判 + 合规施压
 └─ 危险 → 算代价 → 给安全替代

局面性质
 ├─ 我主动 → A 做局
 └─ 我被动 → B 补救

博弈结构（23 篇）
 ├─ 都怕对方先动手 → 囚徒困境 → 先放合作信号
 ├─ 对方开价我被动 → 最后通牒 → 还价 + 给理由
 ├─ 双方硬撑 → 胆小鬼 → 给对方留台阶
 ├─ 不知跟谁 → 协调 → 明确表态
 └─ 很多人抢 → 赢家诅咒 → 先算赢了会不会后悔
```

## 卡 6 · 追问示范（用户回答含糊时）

**用户说**："我想让他付出代价。"

```text
追问：付出什么代价？是让他丢位置、丢钱，还是丢面子？
（把"代价"具体化，才能判断可行性）
```

**用户说**："我就是想要个公道。"

```text
追问：公道具体是什么样子？是他道歉、是他被处理，还是你拿到补偿？
（"公道"是三个不同诉求的混合词）
```

**用户说**："我也不知道该怎么办。"

```text
追问：那说说不怎么办行不行——最不能接受的结果是什么？
（从反面问，比从正面问容易）
```

**用户说**："随便，你给个方案吧。"

```text
追问：我给不了。因为方案取决于你要什么——你是想回原位置，还是想拿一笔走人？
（二选一，逼出真诉求）
```

---

## 一句话

**先问"你要什么"，再问"怎么办"。**

**问错了诉求，再好的方案也是给别人准备的。**
