# 体制内沟通卡

## 用法

对方是公务员、警察、国企、事业单位的人——**换成这套逻辑跟他打交道。**

普通人的逻辑是"值不值得"，他们的逻辑是"**会不会担责**"。你按前者谈，永远谈不通。

---

## 卡 1 · 先换算法

```text
不要问：这样做对他有什么好处？
要问：  这样做他要担什么责任？我怎么帮他免责？
```

**三句话记住**：

- 他们不缺判断，缺**依据**
- 他们不是不办事，是**不敢办没依据的事**
- 让他办事的最好方式：**让他只做转交，不做判断**

---

## 卡 2 · 材料写成"可以直接转交"的形态

他要往上递，你就替他递。

```text
【情况反映】（不要写"控告""举报"——那个词他不敢接）

一、反映人：姓名、联系方式、身份
二、被反映人：姓名、单位、职务
三、事实经过：时间、地点、人物、行为、结果
    （只写能证明的，不写推测。推测会毁掉整份材料的可信度）
四、证据清单：编号、名称、来源、能证明什么
五、诉求（具体动作，不是"希望重视"）：
   1. 立案／受理
   2. 书面受理回执
   3. 申请回避
   4. 请求上级指定异地管辖
六、签名、日期
```

**合格标准：他拿到手，能不能一个字不改就往上报？**

能 → 他会转。不能 → 他会搁置。

## 卡 3 · 官场语言解码

| 他说 | 真实意思 | 你做什么 |
|---|---|---|
| 研究研究 | 不会办 | 换渠道 |
| 按规定办 | 别找我 | 找条文，按条再提一次 |
| 我们很重视 | 转给别人了 | 问"转给谁、何时有结果" |
| 你走程序吧 | 我不担责 | 走程序，每步要回执 |
| 上面有要求 | 我无能为力 | 找"上面" |
| 先回去等消息 | 结束了 | 书面要答复期限 |
| 这个不归我们管 | 推给别的部门 | 让他书面说清归谁管 |
| 你要相信组织 | 别闹 | 继续按程序走 |

**通用铁律：口头的都不算。要书面、要回执、要期限。**

## 卡 4 · 预判他会怎么做

```text
1. 他的上级现在最在意什么？
   □ 稳定 □ 舆情 □ 考核 □ 巡视 □ 上级批示

2. 这件事在他的考核里是什么？
   □ 加分项 □ 减分项 □ 风险项

3. 他做什么最安全？
   按安全程度排：拖 > 上报 > 转办 > 处理

→ 我的动作：把"处理"从最不安全，变成最安全。
   手段：书面留痕 / 明确条款 / 上级关注 / 时间压力
```

## 卡 5 · 三招让他动起来

```text
第一招 · 给他免责凭证
  □ 材料不用他加工
  □ 引用具体条款（哪条法规、哪项规定）
  □ 诉求是具体动作，不是"希望重视"
  □ 一式多份，方便他往上递

第二招 · 降低决策成本
  不要让他判断 → 让他转交
  ✗ "你看这事该怎么处理"
  ✓ "这份材料麻烦转给纪检组，请给我受理回执"

第三招 · 给他向上交差的东西
  □ 材料里写清事实、证据、诉求、可能风险
  □ 让他向上汇报时，直接念你的材料就行
```

## 卡 6 · 造势（体制内版）

**不是喊，不是闹。是让这件事变成"上级关注的事"。**

```text
□ 程序造势：每一步书面、要回执、记编号
   → 形成"这件事在跑"的记录

□ 层级造势：同时向多个层级递，不押单点
   → 任何一层压住，其他层还在跑

□ 时间造势：定期递一次，不等答复就再递
   → 让这件事"过不去"
```

**最有效的是程序造势**——它不需要你认识任何人，只需要你不厌其烦地留痕。**而留痕是他们最怕的。**

## 卡 7 · 三条禁忌

```text
□ 不要试图交朋友
  你越热情，他越防你。按程序、说事实，比请客有效十倍。

□ 不要让他为难
  让他为难的人，会被优先处理掉。
  诉求要写成"他顺手能做的事"，不是"要他破例的事"。

□ 不要一次用完所有牌
  一次全交出去，你就没有第二次了。
  分批、有节奏、每次只递一层——
  让他知道"后面还有"，但不知道有多少。
```

## 卡 8 · 越级举报的矛盾怎么解

**问题**：越级是唯一能绕开关系网的办法，但越级会让办事的人觉得"这人在闹"，反而更不敢接。

**解法**：**用形式解决。**

```text
✗ 不写"控告"、不写"举报"、不写"你们包庇"
✓ 写"情况反映"，走挂号信／EMS，标题写《关于×××有关情况的反映》
✓ 落款写真实姓名和联系方式（匿名件没人敢接）
✓ 结尾一句："以上情况如有不实，本人承担相应责任。"

为什么这样写：
· "反映"是中性词，他有台阶接
· 挂号信有签收，形成时间记录
· 实名+担责，让他知道这不是闹，是认真的
· 你不指控任何人，所以他不需要先判断真假，只需要转交
```

## 一句话

**体制内的人不是不讲理，是讲另一套理：不出事、有依据、能交差。**

你要做的不是说服他，是**让他觉得办你这件事，比不办更安全**。
