# 做局设计器

## 用法

先有评估数据（`knowledge/14` 的试探结果），再设计局。**没有评估数据的局，叫赌博。**

设计顺序不能乱：**饵 → 认知 → 通道 → 代价 → 收口**。任何一件空缺，局就不成立。

---

## 卡 1 · 五零件设计

```text
【饵】他最想要什么？
  → ____________________
  来源：□ 试探得出 □ 第三方 □ 推测（推测要标"未验证"）
  价值校准：略高于他预期 □ 是 □ 否
  他的正常反应应该是："终于等到了" 而不是 "这么容易？"

【认知】他会怎么解释接下来发生的一切？
  → ____________________
  这个解释里，他的利益在哪：____________________
  他可以自己验证的那个点（必须为真）：____________________

【通道】他实际只有一个合理选择，是哪条？
  → ____________________
  其他选项为什么"不划算"：
    □ 截止期过了（客观）
    □ 关键人不在（客观）
    □ 成本上涨（客观）
  ⚠ 障碍必须由环境造成，不能由你造成

【代价】他怎么被锁定？
  □ 沉没成本 □ 公开承诺 □ 既成事实 □ 关系绑定
  具体动作：____________________

【收口】你怎么退出？
  我在局里的角色，事后怎么解释：____________________
  他的损失怎么归因：□ 环境 □ 他自己判断失误 □ 第三方
  我留给他的那个不丢面子的说法：____________________
```

**五件齐全才能动手。缺一件，你会发现自己在临场补，而临场补的一定有破绽。**

## 卡 2 · 评估数据 → 设计转换

```text
【测出他最想要】______ → 做成饵的形状：____________
【测出他最怕失去】______ → 不走进通道的后果＝这件事：____________
【测出他时间很紧】______ → 用他的截止期，不用我的
【测出他信息渠道少】____ → 只控那一个；渠道多 → 各渠道给一致但不完整的版本
【测出他信谁】________ → 让那个人"无意中"说：____________
【测出他的归因风格】____ → 外归因：把损失归给环境；内归因：让他觉得是自己判断失误
【测出他贪婪】________ → □ 加大饵 □ 减小饵拉长时间
【测出他抗压低】______ → □ 用时间压迫 □ 用选项结构
【测出他独立性高】____ → 别用群体压力，用他自己的逻辑推
```

**核心原则**：

> **不要设计"骗他"的局，设计"他自己算完发现这是最优解"的局。**

后者他会替你维护——因为承认被骗比承受损失更痛。

## 卡 3 · 六种局型速查

| 局型 | 结构 | 一句话操作 | 主要风险 |
|---|---|---|---|
| **请君入瓮** | 让他说出方法，再用在他身上 | "如果是你，你会怎么处理？" | 他可能察觉方法被复用 |
| **欲擒故纵** | 先给自由，让他自己选进来 | 摆选项，指出你想要那个的**真实**缺点 | 缺点若是假的，全盘崩 |
| **借刀** | 用第三方，你不出现 | 只给事实，不给方案 | 刀可能转向你 |
| **连环** | 多步嵌套，每步单独看都正常 | 每步都要能中止 | 设计复杂，一处崩全崩 |
| **钓鱼** | 小利引大鱼，先让他赢 | 第一次让他占便宜，第三次用你的条件 | 第一次的血要放得起 |
| **反间** | 让他相信的假情报来自他自己人 | 见 `18-用间与反间` | 三层博弈，玩两层就收手 |

**选型依据**：

- 你力量弱 → 借刀
- 时间充足 → 钓鱼
- 关系要长期 → 连环（每步可解释）
- 对方多疑 → 反间（信息来自他自己人，最不打折）
- 对方自信 → 请君入瓮
- 对方控制欲强 → 欲擒故纵

## 卡 4 · 九真一假编排表

只在必须说谎（D3）时用。**能不说就不说——局比骗耐用。**

```text
要植入的假信息（只允许一条）：____________________

包裹它的真信息（7–9 条，必须可验证）：
  1. ____________（可验证方式：______）
  2. ____________（可验证方式：______）
  3. ____________（可验证方式：______）
  4. ____________（可验证方式：______）
  5. ____________（可验证方式：______）
  6. ____________（可验证方式：______）
  7. ____________（可验证方式：______）

排列检验：
  □ 假信息不在开头（开头会被重点核查）
  □ 假信息不在结尾（结尾会被记住，风险最高）
  □ 假信息前面至少三条真话
  □ 假信息后面至少两条真话
```

**为什么有效**：它利用的是**验证成本**。人不会逐条核实，只会抽查。抽查到三次真的，就停止抽查了。

## 卡 5 · 收口检查（最容易漏）

```text
□ 我在局里的角色，事后能否解释成中性或善意？
□ 他的损失，能否归因到他自己的选择或环境？
□ 我有没有留一个他能接受的说法？
□ 他有没有得到某样东西（哪怕不成比例）？

第 4 项是硬要求。
全输的局一定会被报复——人可以为了一口气不计成本。
```

**收口失败的标志**：**他损失了，但他知道是你做的。**

这时候局就退化成最差的骗，而且是不可修复的那种。

## 卡 6 · 三条铁律

```text
1. 让他做的选择，不能对他全输        □ 遵守
2. 局必须能拆（中途能停，我能退）      □ 遵守
3. 收口在他还能接受的时候             □ 遵守

违反任意一条，就不要做这个局。
```

**关于第 3 条**：贪最后一口是绝大多数局崩掉的原因。对方已经开始怀疑，你还想再拿一点——这一口会让他从"我判断失误"变成"我被耍了"，**而这两种认知对应的报复强度差十倍。**

## 卡 7 · 反做局自检（你进了局吗）

```text
□ 一切都太顺，阻力被人为清除了
□ 有人替我把障碍解决了
□ 我只有一个"合理"选项
□ 对方主动暴露过小缺点（可能在建可信度）
□ 消息来源恰好都是同一个人
□ 有人鼓励我"自己决定"
□ 我已经投入很多，退出很贵

命中三项以上 → 你在局里。

拆法：
1. 强制引入第二个选项（哪怕代价高）——打断通道
2. 倒推时间线：谁在什么时候做了什么，谁最终受益
3. 问"如果这是局，收口在哪"——找到对方的退出点，就知道他想拿什么
4. 故意做一次不符合预期的动作，看谁的反应异常
```

## 一句话

**最好的局，是对方事后复盘，仍然觉得当时那样选是对的。**

不是因为他笨，是因为**你在他的理性范围内，把其他选项都变贵了**。
