# 自我审计表与不败结构

## 用法

每季度一次，30 分钟。**不要每天做**——每天做会变成情绪日记。

打分要低。自评偏高是这里最常见的错误。

---

## 卡 1 · 六项资源

```text
资源      打分1-10   依据（必须具体）                补它的第一步
位置      __         ____________________________    ____________
能力      __         ____________________________    ____________
关系      __         ____________________________    ____________
时间      __         ____________________________    ____________
声誉      __         ____________________________    ____________
退出      __         ____________________________    ____________
```

**打分规则（防自欺）**：

| 项 | 只有满足这个条件才能给 7 分以上 |
|---|---|
| 位置 | 有明确的、别人绕不过去的环节在你手上 |
| 能力 | 有猎头/同行主动找过你，或你的作品在市场上有价 |
| 关系 | 至少三个人，你开口他们会放下手上的事 |
| 时间 | 这件事你能等三个月以上而不受影响 |
| 声誉 | 有人说得出"这个人一定会/一定不会做某事" |
| 退出 | 你手上有具体的、可执行的第二选项 |

**读法**：

- 三项 ≥7 → 可以打
- 一两项高其余 ≤4 → 单点强，最危险的结构
- 全 ≤5 → 别打，按 退出 > 时间 > 能力 > 位置 > 关系 > 声誉 的顺序补

## 卡 2 · 脆弱点七问

```text
1. 我最怕失去什么（具体到一件事/一个人/一笔钱）？
   → ____________________________

2. 谁掌握它？
   → ____________________________

3. 我的腿数：收入__条  关系__条  信息__条
   少于两条的，补法是：____________

4. 我有没有不能见光的事？
   □ 无
   □ 有 → 被谁知道：______  它是筹码还是炸弹：______

5. 我说过不能兑现的话吗？
   □ 无
   □ 有 → 对谁：______  什么时候到期：______

6. 关于最重要的事，我有几个独立来源？
   __ 个（1 个 = 正在被孤立）

7. 我上次被拿捏是什么时候？为什么？
   → ____________________________
   这个模式以前出现过吗：□ 是（第__次）□ 否
```

**第 7 问是核心。** 人被拿捏的模式高度重复——不是遇到不同的人，是同一类结构反复出现。**找出那个结构，才算补上漏洞。**

## 卡 3 · 不败四支柱

```text
【冗余】
  收入来源：__ 条  → 需要补吗：□ 需要 □ 不需要
  关键客户：__ 个  → 需要补吗：□ 需要 □ 不需要
  靠山：__ 个       → 是否单一：□ 是（危险）□ 否
  信息渠道：__ 条   → 是否单一：□ 是（危险）□ 否

【可逆】
  我最近做的一个不可逆决定：____________
  当时有没有可逆的替代版本：□ 有（是什么：______）□ 没有
  下一步要做的决定里，有没有不可逆的：____________

【记录】
  承诺有没有书面化：□ 有 □ 无
  口径有没有留档：□ 有 □ 无
  关键事件时间线有没有整理：□ 有 □ 无

【退出】
  现金：能撑 __ 个月
  备选方案：□ 有（是什么：______）□ 没有
  心理上能接受关系结束吗：□ 能 □ 不能
```

**四项里任一为"危险/无/不能"，先补，别进攻。**

---

## 卡 4 · 弱点分级

```text
【可以公开的弱点】（被利用的损失 ≤ 很小）
  1. ____________________  收益：降低防御 / 换信息 / 立边界
  2. ____________________

【绝不能公开的弱点】（一旦知道就是人质/把柄）
  1. 我真正害怕失去的：____________
  2. 我不能见光的事：____________
  3. 我急于达成的交易：____________
```

**第三项最容易无意泄露。** 检查信号：语速变快、主动降价、反复确认、"这个我们一定要做成"。

## 卡 5 · 季度复评

```text
【上季度定的补强动作】____________
【做了吗】□ 做了，效果：______ □ 没做，为什么：______

【这季度六项资源变化】
  升：______  降：______  没变：______

【这季度被拿捏过吗】□ 没有 □ 有 → 结构是：______
【同一个结构第几次出现】__ 次

【下季度只补一项】____________
【具体第一步】____________
```

**"下季度只补一项"必须遵守。** 补五项等于没补。

---

## 一页速查

```text
我能不能打？ → 六项里有几项 ≥7？三项以上 = 能
我安不安全？ → 四支柱缺几项？缺两项以上 = 先补
我漏在哪？   → 被拿捏的模式第几次出现？第二次以上 = 那是结构问题，不是运气
```
