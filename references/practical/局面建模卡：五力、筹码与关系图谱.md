# 局面建模卡：五力、筹码与关系图谱

## 一、用法

复制下面的卡，填空。**填不出的格子不要编，写"未知"**——"未知"本身就是重要信息，它告诉你下一步该侦察什么。

一次建模 20 分钟。超过 20 分钟还没填完，说明信息缺口太大，先别建模，先去搞信息。

---

## 卡 1 · 五力图

逐项打分 1–10，两边各打一次。

```text
维度        我    对方   差值（我−对方）   依据
决策权      __    __     __              谁签字／谁能否决
资源        __    __     __              钱／人／时间／审批口
信息        __    __     __              谁知道什么、谁知道谁知道
关系        __    __     __              谁能直接找到谁
时间        __    __     __              谁更急、窗口多长

────────────────────────────────────
差值最大的一项：__________（这就是主轴）
```

**读法**：
- 差值最大项为**正** → 你在这个维度有优势，从这里下手
- 差值最大项为**负** → 对方在这里压你，先补这一项，别在别处硬拼
- 五项都在 ±2 以内 → 势均力敌，胜负取决于节奏和信息，见 `knowledge/04`

**常见误填**：
- 「资源」填成"他有钱"——错。资源是**他能调动且愿意为此付出的**东西，不是账面数字。
- 「时间」填成"我不急"——错。时间要看**这件事什么时候必须有结果**，跟你的心情无关。

## 卡 2 · 筹码账本

一张牌一行。写不满三行就别打出去。

```text
筹码          能换什么            什么时候过期        打出去会反伤吗
────────────  ──────────────────  ──────────────────  ──────────────
1. __________  __________________  __________________  ______________
2. __________  __________________  __________________  ______________
3. __________  __________________  __________________  ______________
```

**筹码的五种类型**（对照检查你有没有漏掉）：

| 类型 | 举例 | 特点 |
|---|---|---|
| 信息 | 别人不知道的数据、动向、意图 | 用一次少一次，且会暴露你的信息渠道 |
| 资源 | 预算、人手、审批权、场地 | 可重复使用，但会折旧 |
| 关系 | 能直接找到某人、某人欠你人情 | 用一次消耗一次，最难补充 |
| 时间 | 你能等、对方不能等 | 免费，但需要耐心，最被低估 |
| 否决 | 你能让某件事做不成 | 威力最大，也最招恨，慎用 |

**"什么时候过期"这一栏最重要。** 一个筹码在三个月后可能一文不值（人事变动、项目结束、信息失效）。**很多人的失败是拿一个过期筹码去换东西。**

## 卡 3 · 依赖关系图

画出来，不要只在脑子里想。

```text
        [我]
       /    \
   需要↓      ↑需要
     /        \
 [对方] ——→ [第三方 A]
    \          /
     →[第三方 B]

箭头方向 = "谁依赖谁"
```

**三种结构，对应三种打法**：

| 结构 | 特征 | 打法 |
|---|---|---|
| **单点依赖**（只有你依赖他） | 你弱势 | 造第二个来源，降低依赖 |
| **互相依赖** | 均衡 | 扩大共同利益，别争份额 |
| **他依赖你更多** | 你强势 | 别用尽，留余地（否则他会拼命找替代） |
| **三角结构**（有第三方） | 复杂 | 先判断第三方立场，再动 |

**关键检查**：第三方是**观望者**、**传话人**，还是**潜在盟友**？这三种身份对应完全不同的应对。判断错了，你的动作会传错人。

## 卡 4 · 时间轴

```text
过去        现在                未来
│           │                   │
├─ 关键事件1 ├─ 当前节点         ├─ 对方的时间压力：____
├─ 关键事件2 ├─ 我的窗口：__天    ├─ 我的时间压力：____
└─ 关键事件3 └─ 下一步动作：____  └─ 谁先到期：______
```

**只回答一个问题**：**谁先到期。**

先到期的一方必须先让步。这是谈判里最硬的规律，比实力更硬。

如果你先到期，两个动作：
1. 把交易拆小，先解决能解决的部分
2. 制造对方的截止期（给他一个"过了这个时间就没了"的理由，且必须真实）

## 卡 5 · 退出成本与最坏情形

```text
如果这事完全失败：
  我会损失：______________________（钱／位置／关系／时间）
  我能承受吗：□ 能  □ 勉强  □ 不能
  恢复需要多久：______
  对方会损失：____________________
  对方能承受吗：□ 能  □ 勉强  □ 不能
```

**读法**：
- 你"能"，对方"不能" → 你占优，可以强硬
- 你"不能"，对方"能" → 你弱势，别摊牌
- 双方都"不能" → 这是最危险的局面，双方都会做出非理性动作，**优先降温而不是取胜**

## 二、一页速填版（时间紧的时候用这个）

```text
【争什么】____________________________
【谁更急】____________________________
【我的筹码】____________  【他的筹码】____________
【我最坏能承受】______________________
【第一动作】__________________________
【观察窗口】______天，看什么：__________
【止损条件】如果______，我就______
```

六行。填完就去做，不要再多想。

## 三、填完之后的自检

三个问题，任一答"否"就重填：

1. **我写的"对方的想法"，有可观察的行为支撑吗？**
   没有 → 那是你的推测，标成"假设"，并写一个能证伪它的观察点。
2. **我知道自己最怕什么吗？**
   不知道 → 你还没看清自己的弱点，对方会先看清。
3. **这个局面里，有没有一个人我完全没考虑？**
   有 → 补上。多数败局败在漏掉的第三方。
