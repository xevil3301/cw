# 九地与力度闸门

## 用法

**两次判断，一次动手。**

```text
第一步：认地（我现在站在哪）→ 决定该不该打
第二步：定力度（用多大力）→ 决定怎么打
第三步：过闸（力度 ≥4 时）→ 决定能不能打
```

**顺序不能反。** 先想"怎么打"的人，十次有六次在打一场不该打的仗。

---

## 卡 1 · 认地（四个问题）

```text
① 我退出要付出什么？
   几乎没有 → 散地（不宜开战）
   一点点   → 轻地（不要停在中途）
   很多     → 重地（就地取利，别想退）
   全部     → 死地（先确认真的没退路）

② 对方退出要付出什么？
   退得起 → 交地（双方都能走，别切断联系）
   退不起 → 他在死地，会拼命（别把他逼到墙角）

③ 这块地方双方都要吗？
   是 → 争地（抢先手，不硬抢）

④ 我进去容易出来难吗？
   是 → 围地（找缺口，不硬拼）
```

**九地打法速查**：

| 地 | 一句话打法 |
|---|---|
| 散地 | 别打 |
| 轻地 | 别停，要么深入要么退 |
| 争地 | 抢先，不硬抢 |
| 交地 | 别断联系 |
| 衢地 | 结盟 |
| 重地 | 就地取利，别恋战 |
| 圮地 | 快走，别停 |
| 围地 | 找缺口，别硬拼 |
| 死地 | 拼，但先确认真没退路 |

## 卡 1b · 用地形由五力算（不用猜）

**九地是量出来的，不是感觉出来的。**

```text
先给五项打分（1–10，双方各一次）：
  谁定（决策权）  我__ 他__
  谁有（资源）    我__ 他__
  谁知（信息）    我__ 他__
  谁熟（关系）    我__ 他__
  谁急（时间）    我__ 他__
```

| 差值最大的那一项在哪 | 地形 |
|---|---|
| 我三项以上占优，且退出成本低 | 散地 |
| 只有时间占优 | 轻地 |
| 双方在决策权或资源上咬得很紧 | 争地 |
| 信息我占优，关系持平 | 交地 |
| 决策权＋资源＋关系三项他全占 | 围地 |
| 五项全劣，退出要付出全部 | 死地 |

**改地形，只能改五力：**

```text
散地 → 交地：造第二个信息来源
围地 → 衢地：找一个能替你说话的第三方
重地 → 轻地：把一次性投入拆成几笔
争地 → 散地：拖，让他先沉没
死地 → 围地：造一条退路（哪怕代价很大）
```

**最后一条最重要**：只要有退路，死地就不是死地。**所以"造退路"在任何地形下都是第一优先。**

## 卡 2 · 三种误判（最容易犯）

```text
□ 把围地当死地
  症状：觉得"没退路了，只能拼"
  真相：多数是"舍不得退"，不是"退不了"
  判据：退出只要付出钱/面子/时间 → 你在围地，用计，别拼命

□ 把死地当围地
  症状：已经在墙角，还想"周旋一下"
  判据：退一步就是不可恢复的损失 → 死地，该拼

□ 把重地当散地
  症状：投入很多了，还想着"不行就走"
  判据：退出损失超过一年收入 → 重地，想怎么捞回来，别想走
```

## 卡 3 · 力度五档

**认完地，再定用多大力。**

| 档 | 动作 | 可逆性 | 什么时候用 |
|---|---|---|---|
| **1 不理** | 不回应、不表态 | 完全可逆 | **默认从这里开始** |
| **2 一句话** | 划界、拒绝、要依据 | 可逆 | 对方是习惯性试探 |
| **3 改结构** | 留痕、加见证人、改议程、设标准 | 基本可逆 | 对方反复施压 |
| **4 对等反制** | 一次到位地还手，随即恢复 | 难可逆 | 对方已经在伤害你 |
| **5 摊牌** | 二选一、最后通牒、断供、公开 | **不可逆** | 已准备承担最坏结果 |

**核心规矩：先试 1，不行再 2。** 能一句话解决的事不要用三步。

**大多数人一上来就跳到 4 或 5**，因为那一档最解气——也最短命。

## 卡 4 · 闸门（4 档分两种，走不同的闸）

**原来的三道闸只适合"你出手打他"。弱者在那种闸前面，永远过不去——因为弱的定义就是没证据、没第三方、输不起。**

**所以 4 档必须拆成两种：**

### 4A · 对等反制（你出手打他）

```text
闸一 有明确证据吗？        没有 → 降到 3
闸二 有第三方支持吗？      没有 → 降到 3
闸三 承受得起反扑吗？      承受不起 → 降到 3
```

**这是"打回去"，要求你有牌。没有就降档，没得商量。**

### 4B · 抬高他的成本（你不指控，只让他必须回应）

```text
闸一 有一个可指认的异常吗？        没有 → 降到 3
闸二 有一个会要求他说明的场合吗？   没有 → 降到 3
闸三 他反扑，你扛得住吗？          扛不住 → 降到 3，或换成不暴露自己的方式
闸四 你身上有没有他握着的把柄？     有 → 先处理把柄，再动
```

**闸三是这四道里最容易被忽略、也最致命的一道。**

**为什么必须有**：**抬高成本一定会暴露谁在抬。** 4A 和 4B 都会招来反扑，区别只是 4A 是"打回去"招来的，4B 是"让他麻烦"招来的。**把这一闸删掉，等于假设"温和的进攻不会挨打"——这是错的。**

**反扑的形式，按行业分**：

| 关系 | 他的反扑 | 你扛得住吗 |
|---|---|---|
| 上下级 | 穿小鞋、调岗、不给资源 | 多数人扛得住 |
| 家庭／依赖关系 | **断供**（钱、住处、孩子） | 多数人扛不住 |
| 平台／商家 | **封店、冻结货款** | 现金流在里面的，扛不住 |
| 同行 | 抢客户、压价 | 看现金厚度 |
| 体制内 | 边缘化、不给评优 | 多数人扛得住 |

**判据一句话**：**"他三分钟内能让我损失什么？这个损失我承不承受得起？"**

**答"承受不起" → 4B 这条路不是不能走，是要换一种不暴露自己的走法**：
- 不自己提，让程序自然触发（例：走正常流程，让流程去问）
- 不署自己的名（例：以"经办人"身份提程序性问题，不提实质问题）
- 借别人的口（例：让有程序义务的机构去问）

**闸四的读法**（原句有歧义，这里写死）：**指的是"你身上有没有被他握着的把柄"**，不是"你握着他的把柄"。**有 → 你动他就等于给他理由反打，先处理。**

**为什么闸一比原来严**：**我们社交的主旨是"谁主张谁举证"。**

你没有任何实据就提疑问，对方的反击只有一句——"你凭什么这么说"——**而这一句就能把你打回原形，还顺便把你标记成"爱挑事的人"。**

**所以"可指认的异常"必须具体**：

```text
✅ 一个数字对不上（日期、金额、编号）
✅ 一个时间对不上（谁先说、谁后说、隔了几天）
✅ 一个环节被跳过（该签的没签、该公示的没公示）
❌ "我觉得有问题"（不是异常，是感觉）
❌ "大家都这么说"（不是异常，是传闻）
```

**为什么闸二要求"会要求他说明的场合"**：

**个人对个人，谁主张谁举证；但一旦进入程序，程序要求他说明。**

这就是为什么"有程序义务的机构"比"找盟友"现实——**它们一受理，说明的义务就落到他身上了。**

**场合的三档**：

| 档 | 例子 | 效果 |
|---|---|---|
| **弱** | 私下问、群里随口提 | 他可以不理 |
| **中** | 会上问、书面要求答复 | 他必须给一个说法 |
| **强** | 提交给有程序义务的机构 | **说明义务转移到他身上** |

**4B 的完整机制**（三步，不是"转移举证负担"）：

```text
第一步：你拿出一个可指认的异常（不需要完整证据）
第二步：把它放进一个他必须回应的场合
第三步：他要解释——而解释本身就是成本，解释不清就是损失
```

**判据**：**你说完这句话，他既要回答，又找不出你哪里攻击了他。** 达到这个状态，就是合格的 4B。

**为什么必须有闸**：4A 是不可逆的（关系性质改变）。**而 4B 是可逆的——这也是弱者该优先用它的原因。**

**闸门的作用不是不让你打，是让你知道自己在打多大的仗。**

## 卡 5 · 导师动作：往回拉一档

**用户往往要的力度，比实际需要的高一到两档。**

```text
用户说："我要举报他。"
→ 判断：这是第 5 档
→ 先问：你有证据吗？有第三方吗？承受得起吗？
→ 三缺一：降到 3 或 4
→ 话术："你现在想做的是第 5 档。我们先试第 4 档——
        让他知道你有牌，但不说要什么。不行再往上。"
```

**往回拉的方法，不是讲道理，是给一个更便宜的替代动作。**

| 他想做 | 先给 |
|---|---|
| 举报 | "先让他知道你有"（3 档） |
| 摊牌 | "先划一次界"（2 档） |
| 断供 | "先把条件写清楚"（3 档） |
| 公开 | "先在私下说一次"（2 档） |

**判据**：**如果低一档就能达到目的，高一档就是浪费。**

## 卡 6 · 力度与地形要匹配

| 地 | 建议力度 | 为什么 |
|---|---|---|
| 散地 | 1 | 没有非赢的理由，用力是浪费 |
| 轻地 | 2 | 投入还浅，一句话就够 |
| 争地 | 2–3 | 抢先手靠速度和结构，不靠狠 |
| 交地 | 1–2 | 断联系等于断自己后路 |
| 衢地 | 2 | 结盟靠给好处，不靠压 |
| 重地 | 3 | 就地取利，别恋战 |
| 圮地 | 1 | 环境不利，快走 |
| 围地 | 3–4 | 用计找缺口，必要时反制 |
| 死地 | 4–5 | 拼，但先过三道闸 |

**误配的后果**：在散地用 5 档 → 显得你可怕；在死地用 1 档 → 被人吃干抹净。

---

## 一句话

**先认地，再定档，最后过闸。**

**该不该打，比怎么打重要；用多大力，比说什么话重要。**
