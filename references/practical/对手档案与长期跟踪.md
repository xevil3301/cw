# 对手档案与长期跟踪

## 一、为什么要建档

人的行为有稳定性。**同一个人在同一类局面里，会反复用同一套动作。**

所以你对一个人的历史观察，是他未来行为的**最好预测器**——但前提是你记得住、且记得准。人的记忆会自动修饰，把"他上次让步了"记成"他其实挺好说话"，把"他上次翻脸"记成"他一直很难搞"。

**建档的唯一目的：用记录对抗记忆的自动修饰。**

---

## 二、档案结构（六栏）

| 栏位 | 内容 | 为什么需要 |
|---|---|---|
| **基本盘** | 位置、目标、约束、能调动的资源 | 判断"他能做什么" |
| **收益函数** | 他要什么、他怕失去什么、他的优先级 | 判断"他会怎么选" |
| **行为模式** | 过去三次关键决策中他做了什么 | 判断"他习惯怎么做" |
| **信息渠道** | 他从哪知道消息、他信谁 | 判断"怎么影响他" |
| **弱点与禁区** | 什么事会激怒他、什么事他绝不退让 | 避免踩雷，也避免自伤 |
| **我的假设** | 我对他的判断，附可证伪的观察点 | 防止我把他想成一个固定形象 |

---

## 三、档案模板

```text
【档案 · 代号：______】

■ 基本盘
位置／角色：____________________
他的 KPI 或核心考核：__________
他的上级是谁：__________________
他能调动什么：__________________
他不能做什么（权限边界）：______

■ 收益函数（按重要性排序）
1. 他最想要：____________________
2. 他最怕失去：__________________
3. 他次要想要：__________________
【判断依据】（不是猜的，是观察到的事实）：______________

■ 行为模式（写具体事件，不写评价）
时间      事件              他的动作              结果
________  ________________  ____________________  ________
________  ________________  ____________________  ________
________  ________________  ____________________  ________

■ 信息渠道
他从谁那里得到消息：____________
他最信任谁：____________________
他通过什么形式接收信息（邮件/面谈/群/文档）：______

■ 弱点与禁区
会激怒他的事：__________________
他绝不退让的事：________________
他公开承诺过什么：______________

■ 我的假设（必须可证伪）
假设 1：他更在意 A 而不是 B。
  证伪观察点：如果他在 X 情况下选了 B，这个假设错。
假设 2：他不敢动用 Y 手段。
  证伪观察点：如果他做了一次 Y，这个假设错。

■ 更新时间：______
```

**最关键的是"行为模式"和"我的假设"两栏。**

行为模式只写**事件**，不写评价。"他上次在预算会上砍了 20%，最后接受了 10%"是记录；"他很强势"是标签。**标签无法证伪，记录可以。**

## 四、人物速写：三种常见类型

不是分类学，是**起点假设**。用行为去校正它。

### 型 A · 位置驱动型

- **特征**：行为由 KPI 和上级期待决定，个人偏好影响小
- **应对**：不谈感情，谈"这样做你向上怎么交代"
- **判据**：他的决策能被他的考核指标预测
- **常见错误**：试图用私人关系打动他——对他无效，甚至有害（他会觉得你在让他难做）

### 型 B · 关系驱动型

- **特征**：决策受信任关系影响大，"跟谁熟"比"方案好不好"重要
- **应对**：先建立关系，再谈事。给他安全感，别让他觉得被公事公办
- **判据**：他对不同的人给出的答案不一致
- **常见错误**：只发邮件不打电话——他会觉得你在保持距离

### 型 C · 原则驱动型

- **特征**：有一套自己的规则，违反规则的事坚决不做，符合规则的可以谈
- **应对**：先摸清他的规则，然后在规则内提出方案
- **判据**：他会为原则放弃利益
- **常见错误**：试图用利益交换突破原则——这会被他标记为"不可信"

**注意**：这三种是**起点**，不是结论。多数人是混合型，且在不同压力下切换。**用完就要用行为校正，校正不了就标"未知"。**

## 五、马基雅维利主义倾向的观察（不测，只观察）

`knowledge/00` 提到 Mach-IV 量表。现实中你不会给对手发问卷，但可以观察四个行为指标：

| 指标 | 观察什么 |
|---|---|
| **手段正当性** | 他是否认为"能达到目的的手段都可用" |
| **对人性的看法** | 他是否默认"人都是自私的、可操纵的" |
| **长期 vs 短期** | 他更在意即时收益还是长期信誉 |
| **承诺的稳定性** | 他的承诺在利益变化后是否还成立 |

**四项都高** → 把他当"高操控倾向"处理：**所有约定书面化，所有承诺要求可执行担保，不做单方面投入。**

**四项都低** → 可能是"低操控倾向"，但也可能是"不擅长"而不是"不愿意"。**用行为验证，不要用印象。**

## 六、跟踪节奏

| 频率 | 动作 |
|---|---|
| **每次关键互动后** | 补一行行为记录（30 秒） |
| **每月** | 检查"我的假设"是否被证伪，改掉错的 |
| **每季度** | 重写"收益函数"一栏（人会变，位置会变） |
| **关系重大变化时** | 整份重写 |

**不要每天更新。** 档案的价值在于稳定，频繁修改会让它变成情绪日记。

---

## 七、档案的伦理与安全（工程约束）

三条，做不到就别建：

1. **只记录工作相关的行为**，不记录私生活、健康状况、家庭情况、政治倾向
2. **只记录你亲眼所见或有一手来源的事**，不记录传闻
3. **不建"弱点打击清单"**。这一栏的存在是为了**避免踩雷**（知道什么会激怒他，所以不去碰），不是为了攻击

第 3 条尤其重要。**一份"如何打击某人"的清单，一旦泄露或被引用，你的处境会比对方更糟。** 而一份"如何与他有效合作"的档案，即使被看到也无损。

## 八、用 `scripts/profile_store.py` 存

档案建议存成 JSON，放在工作区的 `profiles/` 下，一个人一个文件。

数据结构（与脚本对应）：

```json
{
  "code": "代号",
  "updated": "2026-10-23",
  "base": {
    "role": "位置",
    "kpi": "核心考核",
    "reports_to": "上级",
    "resources": ["能调动的资源"],
    "limits": ["权限边界"]
  },
  "utility": {
    "wants": ["最想要"],
    "fears": ["最怕失去"],
    "secondary": ["次要想要"],
    "evidence": "判断依据"
  },
  "behavior": [
    {"date": "2026-09-12", "event": "预算会", "action": "砍价 20%", "result": "接受 10%"}
  ],
  "channels": {
    "sources": ["信息来源"],
    "trusts": ["最信任的人"],
    "format": "偏好形式"
  },
  "triggers": {
    "angry": ["会激怒他的事"],
    "non_negotiable": ["绝不退让的事"],
    "public_commitments": ["公开承诺"]
  },
  "hypotheses": [
    {"text": "他更在意 A", "falsified_by": "如果他在 X 下选 B"}
  ]
}
```

**注意 `hypotheses` 这一栏。** 每条假设必须带 `falsified_by`——一个能证伪它的具体观察。**没有证伪条件的假设不是假设，是偏见。**

## 九、一句提醒

**建档的目的是减少误判，不是增加控制。**

一份好的档案，读完的感受应该是"原来他是这样想的"，而不是"原来他这么容易搞"。**前者让你少犯错，后者让你迟早翻车。**
