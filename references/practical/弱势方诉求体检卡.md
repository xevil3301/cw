# 弱势方诉求体检卡

## 用在什么局面

一方经济、信息、社会关系全面依附另一方时（全职照顾者、家庭主妇、随迁配偶、长期病患家属）。

**这类局最大的错，是直接判"不能打"就结束。** "不能打"是结论，不是答案——**答案在"她到底要什么、她能不能走"里。**

---

## 第零问 · 你要的是哪一个（最容易跳过）

```text
□ 让他回来（关系修复）
□ 让他给钱（生活改善）
□ 离开他（离婚／分居）
□ 让他付出代价（报复）
□ 我只是不知道该怎么办
```

**为什么必须先问这个**：四个答案对应四条完全不同的路。

| 她要的 | 正确路径 | 如果搞错 |
|---|---|---|
| 让他回来 | 谈判 + 修复 | 你去教她找工作，等于劝她离婚 |
| 让他给钱 | 谈判 + 施压（4B） | 你去查他出轨，等于把她推向决裂 |
| 离开他 | 造资格（能力＋收入＋证据） | 你让她忍着，等于让她继续消耗 |
| 让他付出代价 | 先摊代价（见 22 篇） | 你帮她报复，最后她承担后果 |
| 不知道 | 先做信息盘点 | 任何方案都是猜的 |

**判据**：**她说不清自己要哪个，就先别给方案。** 因为你在替她定目标——这正是"替他做决定"的另一种形式。

---

## 第一问 · 他的钱花在哪，你有什么依据

**问法**：

> "你们家大概一个月花多少？他给你多少？剩下的你觉得会去哪？"
> "这个'觉得'，是从什么看出来的？"

**目的不是取证，是两个**：

```text
① 判断"这个人还值不值得留"——钱花在另一个家、赌博、还是正常应酬，结论完全不同
② 判断她掌握多少信息——如果她连"一个月花多少"都说不清，她的信息孤岛比想象中严重
```

**⚠ 不要让她把精力全放在"查他"上**：银行流水要诉讼才能调，她能查到的很有限。**查不到会更挫败，而这份精力本该用在造资格上。**

---

## 第二问 · 你为什么想离（不要想当然归因于钱）

**六种常见原因，六种打法——归错因，全盘错。**

| 原因 | 关键动作 | 为什么不同 |
|---|---|---|
| **家暴** | **安全第一，先走再谈**（人身安全保护令、报警记录、临时住所） | 这条**不能"忍"**，忍着等于继续被打 |
| **出轨** | 取证（合法范围内）→ 转化为谈判筹码 | 有证据才谈得上补偿，没证据只是吵架 |
| **性取向／性功能问题** | 一般不作为法律事由，但影响她的自我认知与未来规划 | 重点不在追责，在让她明白"这不是她的问题" |
| **特殊癖好／精神控制** | 识别操控（08 篇）→ 建立外部联系 | 先破孤立，再谈别的 |
| **性格不合／长期冷漠** | 谈判 + 造资格，走和平分手 | 没有过错方，争的是条件不是对错 |
| **经济控制**（只给基本开销、不让工作） | 这本身就是家暴的一种形式（经济暴力） | 很多人不认为这是暴力，需要点破 |

**判据**：**她说"过不下去了"，一定要追问"具体是哪一种"。** 因为"过不下去"可能是六种里的任何一种，而六种的对策几乎不重叠。

---

## 第三问 · 你会什么，你能吃什么苦（关键，但问法要改）

### ⚠ 不要问"你能吃苦吗"

**这是一个社会期望问题——几乎所有人都会答"能"。** 答"不能"等于承认自己懒，没人会这么说。

**改成用过去行为问**：

> "你上一次连续三个月做一件很累的事，是什么？"
> "那时候一天大概几小时？中途想过放弃吗？"
> "你以前有没有靠自己赚过钱？多少？做什么？"

**用行为预测，不用自我评价。** 过去的三个月，比"我能吃苦"这四个字可信十倍。

### 三档结论

```text
A 档：有可变现的技能／爱好
   例：舞蹈、钢琴、小提琴、绘画、烘焙、护理经验、会计、外语
   → 打破信息孤岛：告诉她这些可以赚钱（教学、陪练、接单、上门）
   ⚠ 但要讲清变现周期：从"会"到"能收钱"通常 6–18 个月
     所以现金流不能等，先做快钱，爱好做第二曲线

B 档：没技能，但愿意做体力活
   → 给具体方向：保洁、护工、陪诊、月嫂、食堂、快递分拣
   → 给具体数字：本地护工日薪、保洁时薪（让她看到"一个月能有多少"）

C 档：没技能，也不愿意做
   → 诚实告诉她：你现在不具备离婚的条件
   → 建议：先忍着，但不是白忍——同时做两件事：
      ① 把信息补齐（收入、资产、账户）
      ② 把身体和情绪保住（体检、留一个能说话的人）
```

**C 档最难说出口，但最负责。** 因为给她一个她执行不了的方案，等于让她在最脆弱的时候去撞墙。

## 安全前置检查（必做，放在所有建议之前）

```text
□ 有没有人身暴力？（打过、掐过、威胁过）
□ 有没有限制自由？（不让出门、收走证件手机、跟踪）
□ 有没有威胁孩子？
□ 有没有"你敢走我就……"这类话？

任一项"有" → 不适用本卡的任何"忍"或"谈判"建议
          → 直接转：报警、庇护所、人身安全保护令、信任的人
```

**这一条必须在最前面，因为它会推翻后面所有结论。**

## 一张卡

```text
【第零问】她要的是：□回来 □给钱 □离开 □代价 □不知道
【安全前置】□ 有人身风险 → 停，先走安全流程
【第一问】他的钱：她说得清吗 □ 清 □ 不清
          她判断"钱花在哪"的依据是：____________
          → 这个人还值不值得留：□ 值 □ 不值
【第二问】想离的原因：□家暴 □出轨 □性 □癖好／控制 □性格 □经济控制
【第三问】过去三个月的坚持：____________
          靠自己赚过钱吗：□ 有（多少：__）□ 没有
          档位：□ A 有技能／爱好 □ B 愿做体力活 □ C 都不行

【结论】
  A → 变现路径：______（现金流先做：______）
  B → 具体岗位：______（本地行情：______）
  C → 先忍，同时补信息＋保身体；不具备离婚条件
```

## 一句判断

**"没有进攻解"不是答案，"她还不具备离开的资格"才是答案。**

**而资格是可以造的——只要她愿意付那个代价。**
