# 试探设计器

## 用法

试探不是随口问，是**设计一个场景**。设计四要素缺一个，这次试探就白做。

---

## 卡 1 · 设计四要素

```text
【我要区分哪两个假设】
  假设 A：____________________
  假设 B：____________________
  （两个必须互斥。如果两个都成立，说明这不是一对假设）

【试探动作】（一句话，能直接说出口）
  → ____________________

【如果 A 成立，他会】____________________
【如果 B 成立，他会】____________________
  （两种反应必须可区分。分不清就是设计失败）

【成本】失败了我损失什么：____________（应为"几乎没有"）
【可否认性】被识破时我怎么解释：____________
```

**四要素检查**：

| 要素 | 不合格的表现 |
|---|---|
| 两个互斥假设 | "他可能想要 A，也可能想要 B"——可能两个都要 |
| 可区分的反应 | "他会有点反应"——什么反应算哪种？ |
| 低成本 | 试错要赔钱/丢脸/伤关系 |
| 可否认 | 被问"你是不是在试探我"时说不出话 |

## 卡 2 · 十二种技术速查

| 想测什么 | 用什么 | 一句话动作 | 读法 |
|---|---|---|---|
| 优先级 | **假选项** | "一个快但贵，一个便宜但慢，你选哪个" | 选快＝时间约束；选便宜＝预算约束 |
| 边界柔度 | **小请求** | "能不能帮我确认下这个数据" | 立刻答应＝边界软 |
| 攻击性 | **拒绝测试** | "这个我这周排不开" | 翻脸/记仇＝攻击性高 |
| 信息网络 | **信息投放** | 放一个带独特标记的假消息 | 看它多久传回、从谁传回 |
| 急迫度 | **延时测试** | "我明天答复你" | 当天追问＝他急 |
| 实际权力 | **越权请求** | "这个能不能直接定" | "我得问一下"＝有边界，问谁＝真决策人 |
| 归因风格 | **责任提问** | "这事为什么会搞成这样" | 全推外部＝不会认错 |
| 嘴严程度 | **第三方话题** | 提一个中性的第三方消息 | 传回去＝他会传播你的话 |
| 独立性 | **争议观点** | 提一个明显可争议的判断 | 附和＝可施压；反驳＝群体压力无效 |
| 可信度 | **小承诺** | "明天上午把表发我" | 兑现率 <2/3＝承诺打对折 |
| 抗压 | **时间压缩** | "今天必须定，能不能按这个价" | 让得多＝抗压低 |
| 贪婪 | **小利测试** | 给一个略超约定的小好处 | 越界索要＝贪婪 |

## 卡 3 · 试探记录表

```text
日期      对象      技术        结果              修正后的假设
________  ________  __________  ________________  ____________
________  ________  __________  ________________  ____________
________  ________  __________  ________________  ____________
```

**为什么要记**：单次试探给的是概率，不是结论。**三次同类试探指向同一方向，才算判断成立。**

## 卡 4 · 三层反馈

```text
【第一层·即时】（语气、速度、用词）——可信度低，可以演
  他当场说了：____________
  态度：□ 热情 □ 中性 □ 冷淡 □ 防御

【第二层·延迟】（24–72 小时后他做了什么）——可信度高
  他做了：____________
  和当场说的：
  □ 一致
  □ 不一致（→ 以这一层为准）

【第三层·第三方】（他跟谁说了、怎么说的）——可信度最高
  我听说是：____________
  来源：____________
```

**铁律：第一层只作参考，一律以第二层为准。**

**典型误判**：

| 当场（第一层） | 事后（第二层） | 真实答案 |
|---|---|---|
| "没问题" | 什么都没做 | 不想做，不愿当面拒绝 |
| "我考虑一下" | 主动找你推进 | 想做，但需要台阶 |
| "这事不好办" | 办成了 | 要你付出对价 |
| 热情承诺 | 拖延、失联 | 客套，别当真 |

## 卡 5 · 选级决策表

试探完，按这张表决定用哪一级。

```text
【拒绝测试】他接受我的拒绝了吗？ □ 是 → 正常合作，用结构+关系
                                □ 否 → 习惯性施压，用 C2+C5
【延时测试】他急吗？             □ 急 → 用 C2 时间压迫（成本最低）
                                □ 不急 → 别用时间压迫，无效
【承诺兑现】兑现率 ≥2/3？        □ 是 → 可正常合作
                                □ 否 → 全部书面化 + C5
【越权请求】他有实权吗？         □ 有 → 在他身上花力气
                                □ 无 → 找真正的决策人，别浪费
【归因风格】他认错吗？           □ 认 → 可合作
                                □ 不认 → 冲突前先留痕
【嘴严】他传话吗？               □ 传 → 对他单向屏蔽信息（C1）
                                □ 不传 → 可给关键信息
【抗压】他让得多吗？             □ 多 → 可用施压，但用完要修复
                                □ 少 → 别施压，无效且结仇
【独立性】他附和吗？             □ 附和 → 可用 C3 身份绑定
                                □ 反驳 → 只用结构和利益交换
```

**填完这张表，"选级"就有了依据，不再是凭感觉。**

## 卡 6 · 风险控制

```text
【对同一个人已试探】__ 次（上限 5）
【同一技术对同一个人已用】__ 次（上限 2）
【最近一次被识破】□ 没有 □ 有 → 怎么处理的：______
```

**被识破时的标准收场**：

> "说实话，我确实是在探你的口风。这个事对我挺重要，我不想猜错。"

**为什么有效**：它把"算计"重新定义为"谨慎"。多数人对谨慎是理解的，对算计是反感的。

**绝不能试探的三件事**：

1. 对方的底线（试探底线的方式是越线，而越线不可逆）
2. 对方的痛处（试出来也没用，只会结仇）
3. 涉及第三方利益的事（你试的是他，代价别人付）

---

## 一句话

**判断一个人，不要看他怎么回答你，要看你给了他什么场景、他怎么用。**

回答是表演，场景是考场。
