# 证据链设计卡

## 卡 1 · 先选路线

```text
我要证明的结论是什么（一句话）？
  → ____________________________

选路线（二选一，不可兼得）：
  □ A 可信路线：可验证、有链条、经得起查，但对方能核实
  □ B 不可查路线：口头、匿名、单一来源，说服力打折但不留痕

⚠ 最差的选择是"看起来硬、一查就软"——它会引诱对方去查。
```

---

## 卡 2 · 四要素检查

```text
【来源】谁生成的？他有没有动机？
  这份材料出自：____________
  对方会问的第一个问题是：____________
  我的回答：____________

【时间】什么时候生成的？顺序对吗？
  □ 时间可独立核实（系统日志/第三方）
  □ 时间只有我说了算
  → 若是后者，风险：对方一旦有独立时间线，整条崩

【链条】有没有第二条证据能对上？
  □ 有（是什么：______）
  □ 没有 → 单点证据，抗质疑能力弱

【交叉验证】第三方能不能独立复核？
  □ 能（谁：______）
  □ 不能 → 说服力上限就在这
```

## 卡 3 · 四种重排手法（选一种，别叠）

```text
□ 时间调换：把后发生的事说成先发生
   具体：____________________
   抗鉴定性：极高（所有材料都真，只有顺序错）
   反制风险：对方有独立时间线时会崩

□ 语境剥离：真证据，去掉限定条件
   具体：____________________
   抗鉴定性：中高（对方要调原文才能反证）

□ 归属转移：真文件，换个作者/接收人
   具体：____________________
   抗鉴定性：中（邮件头、签名可反证）

□ 选择性完整：给完整链条，但只给子集
   具体：____________________
   抗鉴定性：极高（没有一条被篡改，只能说不完整）
```

**排序：选择性完整 > 语境剥离 > 时间调换 > 归属转移 > 伪造实物。**

## 卡 4 · 链条自洽三查

```text
1. 互相印证：A 和 B 能对上吗？
   材料 A：______  材料 B：______  接口：______
2. 时间自洽：顺序合理吗？间隔合理吗？
   最短间隔：____  会不会短到不可能？
3. 无解释冲突：需要额外假设吗？
   如果需要"假设某人当时没说真话"才能圆上 → 链条有洞
```

**最容易被忽略的是第 3 条**：一条需要额外假设才能成立的链，一旦被问到就会露。

## 卡 5 · 数字证据可信度

| 类型 | 抗鉴定 | 用法 |
|---|---|---|
| 截图 | 最低 | 只能当引子，不能当依据 |
| 聊天记录 | 低–中 | 配合设备记录才有分量 |
| 邮件 | 中 | 看服务器日志是否对得上 |
| 系统日志 | 高 | 第三方独立生成，几乎无法反驳 |
| 带哈希/时间戳文件 | 最高 | 任何改动都会露 |

**一条规律**：**电子证据的可信度 = 它是否由第三方系统独立生成。** 你自己生成的东西，说服力接近于零。

## 卡 6 · 被指控时怎么反驳（四问）

```text
1. "请提供原始载体，不要截图、不要转述。"
2. "这份文件的创建时间、修改记录、发送日志在哪里？"
3. "它是怎么到你手上的？中间经过了谁？"
4. "除了这份，还有别的独立记录能印证吗？"

开场一句：
> "我不怀疑这份材料的真实性，我只想知道它的完整来源。"

为什么这句好：它不给对方"你在指控我造假"的把柄，
但要的东西和指控一样多。
```

## 卡 7 · 代价核算

```text
□ 时间调换：被识破中，反噬高，法律暴露面高
□ 语境剥离：被识破中高，反噬中，一般不入刑但摧毁信用
□ 归属转移：被识破中，反噬高，伪造文书类风险
□ 选择性完整：被识破低，反噬中高，举证不实的后果
□ 纯伪造实物：被识破高，反噬最高（坐实即全部归零）

我这套材料的被识破概率：____%
被识破后我损失：____________
这个损失比我这一局赢的多吗：□ 是（别做）□ 否
```

---

## 一句话

**最好的证据不是"看起来真"，是"没有人能质疑它的来源"。**

而最高的手段是：**你根本不需要伪造——你只需要决定，谁在什么时候，看到哪一部分真话。**
