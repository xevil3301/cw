# 13 · 自我评估与不败结构

## 一、为什么先盘自己

第 12 篇给了五级手段，但没回答一个前置问题：**你凭什么用？**

手段是要有筹码托底的。**没有筹码的施压叫虚张声势，虚张声势只能成功一次，第二次对方就知道你是空的。** 而多数人的失败不是手段选错，是**高估了自己手里的牌**。

另一个原因更根本：**不败不等于赢。** 不败是"输的时候不伤根本"。一个人可以输十次小的，只要每次都不伤根本，第十一次翻盘。反之，赢十次小的，第十一次把本金赔进去，全盘归零。

**所以这一篇的目标不是让你更强，是让你输得起。**

## 二、资源盘点（六类）

逐项打分 1–10。**打分要低，不要高**——自评偏高是这里最常见的错误，因为你会用"我认识的某人"当成"我的关系"。

| 资源 | 问什么 | 分 |
|---|---|---|
| **位置** | 我在流程的哪个节点？谁必须经过我？ | __ |
| **能力** | 我有什么是不依赖这家公司/这段关系的？ | __ |
| **关系** | 谁能直接接我电话、且会为我办事？（只算三个以内） | __ |
| **时间** | 这件事上，我能等多久？ | __ |
| **声誉** | 别人预期我会怎么做？这个预期对我有利吗？ | __ |
| **退出** | 如果明天崩了，我还有哪些选项？ | __ |

**读法**：

- **六项里有三项 ≥7** → 你有本钱，可以打
- **只有一两项高，其余 ≤4** → 你是"单点强"，最危险的结构，因为对手只需要打你一个点
- **六项全 ≤5** → 别打，先补。补的顺序是：退出 > 时间 > 能力 > 位置 > 关系 > 声誉

**为什么"退出"排第一**：因为退出选项是所有谈判力的来源（BATNA）。**一个随时能走的人，不需要赢任何一局。**

### 一个常被高估的项：关系

> "我认识某总" ≠ "我能让某总为我出手"。

**判据**：你上次找他办事，他答应了吗？办成了吗？没办成，这条关系不计分。

**关系强度只看一件事：他在没有好处的情况下，愿不愿意为你承担成本。**

## 三、脆弱点审计（七问）

这是全篇最重要的一节。**不败的关键不是强化优势，是找到那个一击致命的点，然后处理掉它。**

```text
1. 我最怕失去什么？（具体到一件事、一个人、一笔钱）
   → ______________

2. 谁掌握那个东西？
   → ______________

3. 我的收入／地位／关系，各有几条腿？
   一条 → 极高风险。两条 → 中。三条以上 → 低
   → ______________

4. 我有没有不能见光的事？
   有 → 它现在是筹码还是炸弹？被谁知道？
   → ______________

5. 我最近有没有说过不能兑现的话？
   有 → 谁记得？什么时候会到期？
   → ______________

6. 我的信息渠道有几个？
   一个 → 你正在被孤立，只是还没意识到
   → ______________

7. 我上一次被人拿捏是什么时候？为什么？
   → ______________
```

**第 7 问是核心。** 人一生中被拿捏的模式高度重复——不是遇到不同的人，是**同一类结构反复出现**。找出那个结构，才算真正补上了漏洞。

**案例 · 司马懿称病（248 年）**

司马懿被曹爽排挤，表面称病不出。曹爽派李胜去探病，司马懿"令两婢侍，持衣，衣落；指口言渴，婢进粥，粥皆流出沾胸"，装成行将就木。

**他的自我评估很清楚**：正面实力不如曹爽（曹爽掌兵、掌朝政、有宗室支持），**唯一的优势是曹爽放松警惕后的时间窗口**。所以他把所有资源押在"让对手低估我"这一件事上，而不是硬拼。

**可复用结论**：**当你的六项资源全面落后时，唯一可用的资源是"对方对你的错误判断"。** 而制造这个错误判断的前提，是你清楚自己真实的位置。

## 四、不败四支柱

四项，缺一项就会在某个时刻崩。

### 支柱一 · 冗余

**任何单点依赖都是脆弱点。**

| 单点 | 补法 |
|---|---|
| 只有一个收入来源 | 建立第二收入（哪怕很小） |
| 只有一个关键客户 | 开拓第二个，哪怕不赚钱 |
| 只有一个靠山 | 不要押注单一领导，保持对其他人的可见度 |
| 只有一条信息渠道 | 建第二来源（同事、外部、客户） |
| 只有一项技能 | 学一项能迁移的（写作、谈判、技术判断） |

**冗余的成本是效率。** 这解释了为什么大公司反应慢——它们的冗余多。**但对个人来说，冗余是保命的，不是浪费。**

### 支柱二 · 可逆

**每一步都留撤回空间。**

| 不可逆 | 可逆版本 |
|---|---|
| 辞职 | 先请长假，或先谈内部转岗 |
| 公开决裂 | 私下说清边界 |
| 签独家 | 签有期限的、有退出条款的 |
| 借大钱 | 借小额、多笔、有抵押 |
| 发那条消息 | 写下来，隔一夜再发 |

**判据**：这一步做完，如果判断错了，我能不能退回来？**不能，就先做一个可逆的小版本试探。**

### 支柱三 · 记录

**没有记录的人，在冲突里永远输。**

理由：冲突的本质是"事实之争"，而人对事实的记忆会自动修改，且修改方向总是对自己有利。**当双方都记得对自己有利的版本时，有记录的一方赢。**

三类必须记：

1. **承诺**：谁答应了什么、什么时候、在哪个场合
2. **口径**：同一件事，不同时间点对方说的版本
3. **时间线**：关键事件的先后顺序

**记录不必经过对方同意。** 单向的、礼貌的书面复述就够（见 `practical/被操控时的识别与反制` 法二）。

### 支柱四 · 退出

**随时能走，是最大的谈判力。**

三项准备：

1. **钱**：至少三个月生活费的可动用现金
2. **选项**：至少一个"如果这里不行，我能去哪"的具体方案
3. **心理**：接受"这段关系可能结束"这件事

**第三项最难，也最关键。** 一个不能接受关系结束的人，无论有多少钱和选项，都没有真正的退出能力——因为他的恐惧会被对方读出来。

## 五、把弱点变成武器

弱点不一定要藏。**有些弱点公开出来，收益大于风险。**

### 三种可公开的弱点

| 类型 | 例子 | 收益 |
|---|---|---|
| **能力边界** | "这块我不懂，得请教你" | 降低对方防御，获取信息，显得诚实 |
| **非核心偏好** | "我这人记性差，重要的事请发邮件" | 给对方一个合作说明书，同时把书面化变成习惯 |
| **无关紧要的缺点** | "我不喝酒，别劝" | 建立边界，且成本极低 |

**判据**：这个弱点被利用，我会损失什么？**损失为零或很小的，可以公开；损失重大的，绝对不公开。**

### 三种绝不能公开的弱点

1. **你真正害怕失去的东西**（一旦知道，就是你的人质）
2. **你不能见光的事**（一旦知道，就是你的把柄）
3. **你急于达成这笔交易**（一旦知道，你的 BATNA 归零）

**注意**：第三种最常被无意泄露——语速变快、主动降价、反复确认、"这个我们一定要做成"。


**最后一行只允许两个答案。** 不允许"边打边补"——边打边补的人，两个都做不好。

## 七、一句判断

**知道自己弱在哪的人，比自以为强的人安全十倍。**

因为前者会避开自己的弱点，后者会一头撞上去，还把那次撞墙解释成"运气不好"。
