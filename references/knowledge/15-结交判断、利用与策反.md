# 15 · 结交判断、利用与策反

## 一、先分清三件事

多数人把这三件事混成一件，然后全部做错：

| 概念 | 本质 | 失败方式 |
|---|---|---|
| **结交** | 建立可持续的关系 | 把交易当交情，或把交情当交易 |
| **利用** | 从关系中提取价值 | 提取过度，关系提前耗尽 |
| **策反** | 让人从对方阵营转向你 | 找错人，或给不起他要的东西 |

**核心区分**：结交是**投资**，利用是**提现**，策反是**收购**。三者的会计逻辑完全不同——投资看长期回报，提现看余额，收购看估值和整合成本。

## 二、值不值得结交：六维判断

每一维给 0–2 分。

| 维度 | 问什么 | 分 |
|---|---|---|
| **可预测性** | 他在同类事情上的反应是否稳定？ | __ |
| **互惠记录** | 他受过你的好，回报过吗？（至少一次） | __ |
| **成本对称** | 他为你承担过成本吗？（不只是嘴上支持） | __ |
| **危机表现** | 你出事时，他是靠近还是远离？ | __ |
| **信息质量** | 他给你的信息，事后被验证过几次？ | __ |
| **成长性** | 他在变强还是在原地？ | __ |

**判读**：

| 得分 | 类型 | 处置 |
|---|---|---|
| **10–12** | 资产型 | 长期投入，主动让利，别算计 |
| **6–9** | 交易型 | 按次交换，不投入感情，不留把柄 |
| **3–5** | 观望型 | 保持接触，不给关键信息 |
| **0–2** | 负债型 | 逐步降低接触频率，不撕破脸 |

### 两个单项否决

**只要这两项为 0，总分再高也归为负债型：**

1. **危机表现为 0**：你出事时他远离或落井下石——这种人在你最需要的时候一定不在
2. **互惠记录为 0**：受过好处从不回报——他把你当资源，不是当人

**理由**：这两项测的不是"好不好"，是"**在你弱的时候他会怎么做**"。而楚乌的全部意义，就是在你弱的时候还能活。

### 一个反直觉的判断

**"对我特别好的人"要警惕。**

理由：无理由的过度示好，通常有三种动机——**要你现在给不了的东西、要你将来还、或者要你相信他是个好人**。三者都需要你付出对价，只是账单晚到。

**判据**：他给你的，超出你们关系的正常水平多少？超出的部分，迟早要以某种形式结算。

## 三、利用的三种形态

**"利用"这个词被污名化了，但它是中性技术。** 关键在于**分层**——用错层，关系会提前耗尽。

### 形态一 · 一次性套利

**定义**：用完即止，不投入关系维护。

**适用**：对方是交易型或负债型；这件事只需要他一次；你不打算再见他。

**操作**：把价值一次提干净，同时准备好关系结束。

**代价**：这条路走一次就封了。**别对同一个人用两次。**

**例**：一次性询价、借一次人脉、用一次他的渠道。

### 形态二 · 长期共生

**定义**：互相依赖，双方都在增值。

**适用**：对方是资产型；你们会长期打交道。

**操作**：

1. **先给**，且给的东西对他有真实价值
2. **让利**，但让在他看得见的地方
3. **不一次提完**——共生关系的关键是"余额始终大于零"
4. **主动维护**，不等他开口

**核心指标**：**他对你的依赖，和你对他的依赖，都不要归零。** 一方归零，共生就退化成单向利用。

### 形态三 · 工具化

**定义**：纯执行关系，不谈交情，按契约走。

**适用**：能力可用但人品不可信的人；标准化的工作。

**操作**：合同化、流程化、留痕、不给自由裁量空间。

**代价**：效率低（因为要防），但风险也低。

**关键**：**工具化最忌讳"临时讲感情"。** 你一旦在工具关系里讲交情，对方会重新定价，而你没有对应的约束手段。

### 分层错误对照

| 错误 | 后果 |
|---|---|
| 把资产型当工具化 | 关系降温，你失去一个长期支点 |
| 把负债型当共生 | 被持续消耗，且他会先撤 |
| 把交易型当资产型 | 你投入感情，他按次结算，你觉得被背叛 |
| 在工具关系里讲交情 | 对方重新定价，你失去约束 |

## 四、结交的操作：三步

### 第一步 · 先给，且给在暗处

**给什么**：信息 > 引荐 > 资源 > 钱。

**为什么信息排第一**：信息可以给多次、成本低、且每次给都增加对方对你的依赖。钱只能给一次，且给完就结束。

**"给在暗处"的意思**：不要在众人面前给。**公开的给予是施恩，暗处的给予是人情。** 施恩要求回报，人情不要求——而人情更贵。

### 第二步 · 小步测试

给完之后，提一个**很小的**请求。

**读法**：
- 立刻办 → 可继续
- 拖着但办了 → 可继续，但别指望紧急时刻
- 不办也不解释 → 停止投入

**这一步是筛选，不是索取。** 你要测的不是他能不能办，是他**愿不愿意为你花成本**。

### 第三步 · 共同经历

**最强的绑定不是利益，是共同经历过的麻烦。**

一起扛过一次危机、一起熬过一个项目、一起背过一次锅——**这三种经历建立的信任，比十次饭局管用。**

**操作**：主动制造共同承担的场景。不是制造危机（那是玩火），是在真实危机出现时，选择和他站在一起。

## 五、策反：从对方阵营拿走一个人

### 5.1 先判断值不值得策反

**五个条件，至少满足三个再动手：**

| 条件 | 判断方法 |
|---|---|
| **他有不满** | 他抱怨过什么？抱怨的对象是不是他的上级/阵营？ |
| **他有能力** | 他手上的东西，换个人能不能替代？ |
| **他位置关键** | 他走了，对方会不会痛？ |
| **他被低估** | 他的贡献和回报是否不匹配？ |
| **他有退路焦虑** | 他是否担心自己的将来？ |

**最重要的一条是"不满"，但最不可靠的也是它。**——**抱怨不等于想走。** 很多人抱怨只是为了减压，你一旦当真去挖，他会立刻回去表忠心，用你的邀请当他忠诚的证明。

**判据**：他抱怨的时候，有没有提出过具体的替代方案？提过 → 真在想走；只抱怨不给方案 → 只是在减压。

### 5.2 五步操作

**第一步 · 找裂痕**

不是制造裂痕，是**发现已经存在的裂痕**。制造裂痕风险极高，且通常会被察觉。

观察三个点：他和上级的互动频率、他最近是否被排除在关键会议外、他的功劳是否被归给别人。

**第二步 · 给替代**

**不要先谈"过来帮我"，先给他现在没有的东西。**

| 他缺什么 | 你给什么 |
|---|---|
| 被看见 | 在公开场合提他的贡献 |
| 决策权 | 让他参与一个他能拍板的项目 |
| 安全感 | 明确告诉他"最坏情况我兜底" |
| 成长 | 给他一个能学到东西的机会 |
| 钱 | 最后再谈，先谈别的 |

**顺序很重要**：先给非金钱的，后给金钱的。**因为先给钱，你就把自己定义成了买家；先给别的，你定义成了同盟。**

**第三步 · 降风险**

**策反最大的障碍不是利益不够，是风险太高。**

他真正怕的是：**万一你输了，我怎么办？**

**必须回答的三个问题**：

> "如果我过去，原来的位置还保得住吗？"
> → 给出具体的、可验证的承诺（书面、有见证人）

> "如果这事传出去，我怎么做人？"
> → 给他一个体面的叙事（"不是背叛，是理念不同"或"是正常流动"）

> "你凭什么觉得你能赢？"
> → 给事实，不给信心。**展示你已有的筹码，不是展示你的决心。**

**第四步 · 小步验证**

**别一上来就要他做大事。** 先让他做一件小事——小到即使他告发你，也无损于他。

**读法**：
- 他做了，且没外传 → 继续
- 他做了，但传出去了 → 他在两头下注，**停止**
- 他不做 → 他只是想听你说，**停止**

**这一小步的本质是"投名状"，但设计上要轻——重了会吓退，轻了测不出来。**

**第五步 · 公开绑定**

**这是最后一步，也是最危险的一步。**

只有在第四步通过之后，才让他做一件**公开的、无法解释为中立**的事。

**为什么必须公开**：因为**只有不可逆的行动才能锁定立场**。私下帮你十次，他随时可以回去；公开帮你一次，他回不去了。

**代价**：这一步之后，他和原阵营的关系基本结束。**所以做之前要确认：你真的需要他吗？你能接住他吗？**

### 5.3 策反话术（按步骤）

**找裂痕阶段的试探**（不可否认）

> "你们那个项目，我听说功劳记到别人头上了？我可能听错了。"

**给替代阶段**

> "你们那个方案我看过，思路是对的，可惜没推下去。如果是我，我会让它先跑一个小范围。"

**不给邀约，只给认可。** 认可会让他自己来找你。

**降风险阶段**

> "你不用现在决定，也不用做任何事。我只是让你知道，如果有一天你想换个环境，我这边有个位置。"

**"不用现在决定"这句话是关键**——它把压力降到零，也把主动权留给他。

**第五步之后**

> "这次的事，我会在公开场合说清楚是你的判断。剩下的事我来处理。"

### 5.4 策反的三个致命错误

| 错误 | 后果 |
|---|---|
| **找抱怨最多的人** | 抱怨多的人往往行动最少，且他会拿你的话去表忠心 |
| **先谈钱** | 你被定义成买家，价高者得，随时被别人加价买走 |
| **过早要求公开表态** | 他还没下定决心，你逼他，他会选原来那边 |

## 六、反策反：防止你的人被挖

四条，从最有效到最弱：

1. **不给可乘之机**：让核心人员有决策权、被看见、拿得到应得的。**被低估的人最容易被挖**
2. **制造共同经历**：一起扛过事的人，挖走的成本高得多
3. **提高离开成本**：不是威胁，是**让他在这里的沉没资产更多**（长期项目、团队关系、专业积累）
4. **监测异常**：他突然开始关心别处机会、突然低调、突然和某人频繁接触

**最有效的还是第一条。** 挖角成功率高，通常不是对手给得多，是**这边给得太少**。

## 七、案例 · 陈平离间（前 204 年）

**局面**：楚汉相持，项羽强，刘邦弱。项羽唯一的智囊是范增。

**手段**：刘邦给陈平黄金四万斤，任其使用。陈平的做法不是收买，是**制造猜疑**：

1. 项羽使者来，陈平先以最高规格接待，见使者后故意惊讶："我以为是亚父（范增）的使者，原来是项王的使者。"随即撤去好菜，换粗食。
2. 使者回去报告，项羽开始怀疑范增。
3. 范增建议急攻荥阳，项羽不信；范增怒而辞官，途中病死。

**拆解**：

- 这**不是策反，是"制造不信任"**——比策反便宜，也比策反狠
- 关键操作是**让对方的使者自己得出错误结论**，陈平没说范增一句坏话
- **代价极低**：四万斤黄金，一个人没死

**可复用结论**：

1. **拆解一个联盟，最便宜的方法不是挖人，是让双方互相怀疑**
2. **最高级的信息操作，是让对方"自己发现"你想让他发现的事**
3. **前提是对方多疑**——项羽若信任范增，这招无效。**所以先评估对手的性格，再选手法**

**同时这也是"策反"的边界**：策反一个不满的人，成本是他要的价；离间两个信任的人，成本只是一点信息差。**能用离间解决的，不必策反。**

## 八、一句判断

**结交看他在你弱的时候怎么做，利用看你在他弱的时候怎么做，策反看他在两边都弱的时候怎么选。**

三个场景，测的是同一样东西：**在没有好处的时候，他站在哪。**
