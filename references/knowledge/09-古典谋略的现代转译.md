# 09 · 古典楚乌的现代转译

## 一、转译的原则

古典文本的问题不是过时，是**语境缺失**。同一个词，在君臣关系里和在同事关系里，成本和后果完全不同——前者输一次是死，后者输一次是离职。

所以转译必须做三步：

1. **还原原始约束**：当时什么条件下这招成立
2. **剥离道德外衣**：去掉"忠""义""礼"的表述，看底下的利害结构
3. **重算现代成本**：在当代环境里，同样的动作会触发什么

**只有第 3 步做完，古典才是可用的。** 否则就变成背名句。

## 二、《三十六计》：六套情境分类

三十六计的价值不在三十六条计，在**它的分类维度**：按"我方处境"分六套。

| 套 | 原义 | 现代对应处境 |
|---|---|---|
| **胜战计**（1–6） | 优势时用 | 你占上风，如何扩大战果而不招恨 |
| **敌战计**（7–12） | 势均力敌时用 | 僵持局面，如何创造不对称 |
| **攻战计**（13–18） | 主动进攻时用 | 你要夺某个位置／资源 |
| **混战计**（19–24） | 多方混战时用 | 局面混乱、多方博弈 |
| **并战计**（25–30） | 兼并盟友时用 | 合作方整合／收编 |
| **败战计**（31–36） | 劣势时用 | 你在下风，如何止损或翻盘 |

**这个分类的真正用处**：**先定位自己的处境，再选计。** 多数人失败是因为在劣势时用胜战计的招（硬碰），或者在优势时用败战计的招（委曲求全，反而暴露虚弱）。

### 几条最常被误用的

| 计 | 常见误用 | 正确前提 |
|---|---|---|
| **瞒天过海**（1） | 当成"撒谎" | 原义是"在公开的常规动作里藏真实意图"——不是造假，是**利用对方的习以为常** |
| **借刀杀人**（3） | 当成"挑拨" | 原义是"自己不出现，借第三方力量"——前提是你和第三方有真实共同利益，否则刀会转向 |
| **以逸待劳**（4） | 当成"不动" | 前提是**对方在消耗**。若对方不动，你也干等，就是双输 |
| **趁火打劫**（5） | 当成"落井下石" | 前提是你能控制火势。火一旦失控会烧到你 |
| **无中生有**（7） | 当成"造谣" | 原义是"从虚到实，逐步做实"——造谣只是第一层，没有后续做实，就是一次性消耗 |
| **隔岸观火**（9） | 当成"旁观" | 前提是火不会烧到你这边。要预先划清界限 |
| **笑里藏刀**（10） | 当成"表面友好" | 原义是"让对方放松戒备，同时准备"—**关键在准备，不在笑** |
| **李代桃僵**（11） | 当成"找替罪羊" | 原义是"用局部损失保全整体"。找替罪羊是转移责任，两回事 |
| **顺手牵羊**（12） | 当成"占便宜" | 原义是"在主目标之外，取微小的额外收益"—**微小的**，大了就变成新战线 |
| **树上开花**（29） | 当成"虚张声势" | 原义是"借现有条件造势"—虚张声势一旦被验证就崩，借势造势可持续 |
| **反客为主**（30） | 当成"夺权" | 原义是"逐步渗透，从被动到主动"—**逐步**是关键，一步到位就是政变 |
| **走为上**（36） | 当成"逃跑" | 原义是"在不利局面下保全实力"—判断标准是**保存的东西还值不值得保** |

## 三、《韩非子》的三组工具

### 1. 八奸（已详述于 03 篇）

近身操控的威胁模型，八术配八防。**核心是：把"谁给的好处"和"谁做的决定"绑回同一主体。**

现代应用：当你发现团队里有人既在分配资源又在评价结果，且两者不一致时，八奸的结构就出现了。

### 2. 七术（《内储说上》）

韩非列举君主控制臣下的七种手段：**众端参观、必罚明威、信赏尽能、一听责下、疑诏诡使、挟知而问、倒言反事**。

其中三条对现代组织最有价值：

- **众端参观**：多源验证，不听一面之词。（对应现代：交叉信息源）
- **挟知而问**：明知故问，测试对方是否诚实。（对应：面试、尽调中的验证性提问）
- **倒言反事**：说反话，看谁附和。（对应：会议上故意提一个错误方案，看谁盲从——这条有伦理问题，慎用）

### 3. 六微（《内储说下》）

六种隐蔽的危机苗头：**权借、利异、似类、有反、有参、敌国**。

- **权借**：权力被借用（下属借你的名义行事）
- **利异**：利益不一致的人在同一条船上
- **似类**：表面相似、实质不同的事被混淆
- **有反**：有前科的人被重新任用
- **有参**：多方牵制导致无人负责
- **敌国**：外部力量介入内部

**这六条是极好的组织诊断清单**，比大部分现代管理咨询框架更简洁。

## 四、《君主论》的核心命题

马基雅维利真正有价值的不是"为达目的不择手段"（这是误读），而是三个结构性命题：

### 命题一：新获得的权力最不稳定

"再没有比率先建立新制度更困难、更危险、更不确定成功的了。"（《君主论》第六章）

**原因**：旧制度的受益者会全力反对，新制度的受益者只是温吞的支持者。

**现代应用**：空降管理者、新官上任、并购整合——**前 90 天不是做事的时候，是处理"旧受益者"的时候**。

### 命题二：恐惧与爱不可兼得时，选恐惧——但不要被憎恨

第十七章：受人畏惧比受人爱戴更安全，因为"爱靠不住，恐惧靠得住"。但紧接着一条限制：**必须避免被憎恨**。被憎恨的三个来源是：**侵夺他人的财产、侵犯他人的妻女、以及无理由的残酷**。

**这一条经常被漏掉。** 马基雅velli 说的不是"狠就行"，是"**狠要有限度，且有明确禁区**"。禁区是财产、尊严、以及无必要的暴力。

**现代转译**：你可以让人怕你的标准，但不要碰人的钱、不要羞辱人、不要为立威而处罚。**碰了这三样，恐惧就转成仇恨，而仇恨不计成本。**

### 命题三：君主必须自己掌握军事

第十二至十四章反复强调：雇佣军和外国援军都不可靠，必须有自己的武装。

**现代转译**：**核心能力不能外包。** 你可以外包执行，不能外包判断；可以借力，不能借命。

## 五、《罗织经》：反面教材的价值

来俊臣《罗织经》成书于唐武则天时期，是构陷的流水线手册。共十二篇（阅人、事上、治下、控权、制敌、固荣、保身、察奸、谋划、问罪、刑罚、瓜蔓）。

**为什么收进来**：因为它把构陷拆解成了**可识别的工序**。见过完整流程的人，能在第一步就察觉。

**它的结构（用于识别，不用于执行）**：

1. **择人**：选没有靠山、有把柄、人缘差的人
2. **造端**：从一件小事开始，赋予其政治含义
3. **牵连**：把无关的人拉进来，使案件规模超过个人恩怨
4. **成狱**：用刑求口供，用口供牵连更多人
5. **固案**：让案件变成既成事实，使翻案成本高于认罪

**识别要点**：**当你发现一件小事正在被"赋予含义"、且开始牵连无关的人时，第 2 步已经发生。** 此时唯一有效的是**把事情拉回事实层**：具体的、可核查的、有时间地点的那一层。

**同时必须说清**：这份东西的方法在任何当代法律体系下都构成犯罪（诬告陷害、伪证、刑讯逼供）。收它的唯一目的是**识别工序**，不是学工序。

## 六、转译对照表

| 古典概念 | 原始约束 | 现代对应 | 成本变化 |
|---|---|---|---|
| 君臣（生死关系） | 输一次即死 | 上下级（可离职） | 成本大降，手段可更温和 |
| 臣（无退出权） | 不能走 | 员工（可跳槽） | 强制手段基本失效 |
| 兵权 | 暴力垄断 | 核心资源／决策权 | 从"可夺"变"难夺"，需换方式 |
| 名分 | 合法性唯一来源 | 头衔、职级、授权 | 仍然重要，但可绕过 |
| 连坐 | 家族担保 | 团队连带责任 | 弱化，但仍以"项目组"形式存在 |
| 信息垄断 | 竹简、驿传 | 会议、群聊、汇报链 | 更易被打破，但仍有效 |

## 七、使用古典的四条纪律

1. **不背名句，只取结构**。"知己知彼"没有信息量，"知道自己缺什么信息"才有。
2. **先问原始约束**。这招在原环境下成立的前提是什么？那个前提现在还在吗？
3. **不做道德翻译**。古典里的"忠"在现代对应"职业信用"，不是"愚忠"。翻译错了，结论就错。
4. **反面教材同等收录**。识别能力来自见过坏的，这是本 skill 的一贯立场。
