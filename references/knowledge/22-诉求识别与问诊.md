# 22 · 诉求识别与问诊

## 零、为什么不能直接给答案

用户说的问题，通常不是他真正的诉求。

同一句"我被调去边缘项目了"，背后可能是五种完全不同的东西：

| 他嘴上说的 | 他真正想要的 |
|---|---|
| "我想回去" | **复位**——回原位置、原待遇 |
| "我不能就这么算了" | **补偿**——钱、职级、机会 |
| "他凭什么这么对我" | **报复**——让他付出代价 |
| "所有人都看着" | **面子**——公开场合的尊严 |
| "我怕他下一步……" | **安全**——不出事、不被清 |

**这五种诉求，对应五套完全不同的打法。** 判断错了，方案再精致也是废的。

**而直接给方案，等于替用户把他的诉求定了。** 这是越权，也是最常见的错误。

---

## 一、问诊三问（必须先问）

```text
1. 你最想要的结果是什么？具体到"什么状态算成了"。
2. 你能接受的最大代价是什么？（钱、位置、关系、时间）
3. 如果这事最后没解决，你怎么办？
```

**第二问最关键。** 它决定了手段的上限——**能承受大代价的人可以用重手，承受不起的只能用结构手段。**

**第三问测退路。** 答"没想过"的人，其实没有退路，此时任何进攻都是赌。

---

## 二、听三个词，判诉求

用户说话时会不自觉泄露目标。**听到这三类句式，基本可以定性：**

| 他说 | 诉求 |
|---|---|
| "我本来应该……"／"我原来……" | **复位** |
| "不能就这么算了"／"总得有个说法" | **补偿**或**面子** |
| "我要让他……"／"他也得尝尝" | **报复** |
| "我怕……"／"万一他……" | **安全** |

**如果他反复说同一句，那句话就是他的真实诉求，不是他描述的那个问题。**

---

## 三、三类诉求，三条路

### 第一类 · 正当诉求（复位、安全）

**打法**：五力法 + 谈判 + 向上管理。

**特点**：目标明确、可谈、有正当性。这类最好办。

**你的角色**：算账 + 给路径。

### 第二类 · 灰色诉求（补偿、面子）

**打法**：谈判 + **合规施压**（见下节）。

**特点**：目标合理，但手段容易越界。

**你的角色**：帮他把手段拉回合规区，同时不让步于结果。

### 第三类 · 危险诉求（报复、用证据换利益）

**打法**：**先给成本，再给替代方案。**

**不是拒绝他，是让他看见代价。**

```text
"这条路能走，但你要知道三件事：
 一、你现在手上的东西不完整，用出去可能反过来伤你；
 二、一旦你提了条件，性质就从'他违规'变成'你敲诈'；
 三、你还有房贷和孩子。
 如果你还是要走，我给你一条不会把自己搭进去的走法。"
```

**关键**：**不劝，只算账。** 把代价摊开，让他自己选。

## 四、合规施压：告知 ≠ 要挟

这是本篇最实用的一节。**很多人想用手上的东西换利益，结果把自己变成被告。**

**分界线只有一条：你有没有提出要求。**

| 做法 | 性质 |
|---|---|
| "你把位置还给我，我就不说" | **敲诈** |
| "我手上有这些东西"（不附带任何条件） | **合法** |
| "你自己看着办" | 灰色，但通常不构成 |
| 让第三方知道你有 | **合法** |
| 把材料放在他能看到的地方 | **合法** |

### 三种安全做法

**做法一 · 让第三方知道你有**

不给他看，让别人知道"我手上有东西"。**他会自己算，你什么都没说。**

**做法二 · 在无关场合提一句**

> "这些东西我留着也没用，哪天清理电脑就删了。"

**这句话没有要求，但传递了三个信息**：我有、我知道你知道、我暂时不用。

**做法三 · 把东西放在他能看到的地方**

不主动展示，但让它"偶然可见"。**人对自己发现的东西，比被告知的更当真。**

### 为什么这样有效

因为**压力不来自你的要求，来自他的计算**。他自己算完，会得出"这人不好惹"的结论——而你没有留下任何可以指证你的东西。

**这就是"不主动出击"的真正价值：不是软弱，是不给对方留证据。**

---

## 五、为什么主动出击更容易输

| 主动出击 | 后果 |
|---|---|
| 先举报 | 你要举证，举证不成就是诽谤 |
| 先谈判 | 你先开价，就暴露了底价 |
| 先翻脸 | 你先破的规矩，责任在你 |
| 先动手 | 你成了挑起冲突的人 |

**防守反击的本质是：让对方承担"先动手"的成本。** 他先动，他举证；他先动，他破规矩；他先动，旁观者记得的是他。

**你只做一件事：接住，然后回应。** 这就是"以不变应万变"。

## 六、问诊之后的判断树

```text
问完三问 → 判诉求类型
  ├─ 正当（复位/安全）→ 五力法 + 谈判
  ├─ 灰色（补偿/面子）→ 谈判 + 合规施压
  └─ 危险（报复/换利益）→ 摊开代价 → 给安全替代路径

再看局面性质：
  ├─ 我主动 → A 做局系统
  └─ 我被动 → B 补救系统

最后看对手性质：
  ├─ 有意图的人 → 心理战
  ├─ 有规则的组织 → 程序战
  └─ 有算法的系统 → 接口战
```

---

## 七、一句判断

**先问"你要什么"，再问"怎么办"。**

**问错了诉求，再好的方案也是给别人准备的。**
