# 24 · 九地：局面坐标与切换

## 零、为什么先认"地"

孙子把战场分成九种地形，每种给一套打法。**它的价值不在分类，在于告诉你：同一套动作，在不同地形上结果相反。**

**认错地形，力气就用错。** 这是比选错手段更早、更致命的错误。

（原文：「用兵之法，有散地，有轻地，有争地，有交地，有衢地，有重地，有圮地，有围地，有死地。」白话：用兵的方法，有散地、轻地、争地、交地、衢地、重地、圮地、围地、死地九种。）

---

## 一、九地对照表

| 地 | 孙子原话（白话） | 现代对应 | 打法 |
|---|---|---|---|
| **散地** | 在本国作战，士兵容易逃散 | 你随时能抽身，没有沉没成本 | **不宜开战**——没有非赢不可的理由，打了反惹麻烦 |
| **轻地** | 进入敌境不深 | 刚介入，投入还浅 | **不要停在中间**——要么深入，要么退出 |
| **争地** | 我得有利，他得也有利 | 双方都要的：晋升名额、独家客户 | **不要硬抢，要抢先手** |
| **交地** | 我能去，他也能来 | 多方往来：跨部门、行业人脉 | **不要切断联系**——切断就是断自己后路 |
| **衢地** | 多国交界，先到者得众 | 多方交汇的关键节点 | **结盟** |
| **重地** | 深入敌境，背后城邑多 | 已投入很多，退不干净 | **就地取利，不要恋战** |
| **圮地** | 山林险阻沼泽，难走 | 环境恶劣：公司要倒、行业下行 | **快速通过，不要停** |
| **围地** | 进去的路窄，回来的路远 | 进退两难，两边都有成本 | **用计，不硬拼**——找缺口 |
| **死地** | 不速战则亡 | 已被逼到墙角，没有退路 | **拼**——但先确认真的没退路 |

（原文打法：「散地则无战，轻地则无止，争地则无攻，交地则无绝，衢地则合交，重地则掠，圮地则行，围地则谋，死地则战。」）

---

## 二、地形决定"该不该打"，不是"怎么打"

**九地最反直觉的一点：前三种地形，孙子都说"不要打"或"不要停"。**

- 散地无战 → 你没有非赢的理由，打是浪费
- 轻地无止 → 停在浅处最耗，不如决断
- 争地无攻 → 双方都要的地方，硬攻成本最高

**这三条，正好治两种病**：**该退不退（停在轻地）、不该打偏要打（在散地开战）。**

## 三、三种最常被误判的地

### 误判一 · 把围地当死地

**症状**：觉得"我没退路了，只能拼"。

**真相**：多数"没退路"是**舍不得退**，不是退不了。

**判据**：如果退出这件事只需要付出钱、面子或时间，那你就在围地，不在死地。**围地的正解是用计找缺口，不是拼命。**

**代价**：把围地当死地，你会做出不可逆的动作，而那个动作本来不必做。

### 误判二 · 把死地当围地

**症状**：已经被逼到墙角了，还在想"怎么周旋一下"。

**真相**：该拼的时候不拼，会连拼的机会都没有。

**判据**：如果退一步就是实质性的、不可恢复的损失（比如失去全部收入、失去自由），那是死地。

### 误判三 · 把重地当散地

**症状**：已经投入很多了，还想着"不行就走"。

**真相**：你走不掉——沉没成本太高。

**判据**：退出要损失多少？超过你一年收入，就不是散地。**在重地要做的不是想退，是想怎么把已投入的捞回来。**

## 四、地形会变（这是切换的根据）

**同一件事，地形会随时间和你的动作改变。**

```text
散地 → 你介入了 → 轻地 → 投入变多 → 重地 → 退不干净 → 围地 → 无路可退 → 死地
```

**也可能反向**：

```text
围地 → 找到缺口 → 交地 → 关系变好 → 衢地（可以结盟）
```

**推论**：

1. **每次动作之后，重新认一次地。** 这是"切换自如"的机制——不是换系统，是重新看自己站在哪。
2. **主动选择"往哪个地走"。** 你可以选择从轻地退回散地（及时止损），也可以选择深入重地（全力投入）。**但不要停在轻地。**
3. **在重地和围地，优先做"改善地形"的动作**，而不是"赢"的动作。因为地形不对，赢了也守不住。

## 五、认地的四个问题

```text
1. 我退出这件事，要付出什么？
   几乎不付出 → 散地
   付出一点 → 轻地
   付出很多 → 重地
   付出全部 → 死地

2. 对方退出，要付出什么？
   他退得起 → 交地（双方都能走）
   他退不起 → 他在死地，会拼命

3. 这块地方，是不是双方都要？
   是 → 争地：抢先后，别硬碰

4. 我进去容易出来难吗？
   是 → 围地：找缺口，别硬拼
```

## 七、九地由五力测出（嵌套）

**九地不是一个凭感觉选的标签，它是可以被测量出来的。**

因为九地的本质是两个变量：**退出成本**和**依赖结构**。而这两样，正好是五力图量的东西（决策权／资源／信息／关系／时间）。

### 判定表

| 五力状态 | 地形 | 理由 |
|---|---|---|
| 三项以上占优，且退出成本低 | **散地** | 你随时能走，没有非赢的理由 |
| 只有时间占优，其余持平 | **轻地** | 你能等，但投入还浅 |
| 双方在同一项（决策权或资源）咬得很紧 | **争地** | 双方都要，谁先动谁占先 |
| 信息项你占优，关系项持平 | **交地** | 你能自由往来，对方也能 |
| 决策权＋资源＋关系三项对方全占 | **围地** | 你进得去，出不来 |
| 五项全劣，且退出要付出全部 | **死地** | 真没退路 |

### 改地形只能改五力

**用力气改不了地形。在围地拼命，只会死得更快。**

| 想改什么 | 动哪一项 | 具体动作 |
|---|---|---|
| 散地 → 交地 | **信息** | 造第二个信息来源 |
| 围地 → 衢地 | **关系** | 找一个能替你说话的第三方 |
| 重地 → 轻地 | **时间** | 把一次性投入拆成几笔 |
| 争地 → 散地 | **时间** | 拖，让对方先投入、先沉没 |
| 死地 → 围地 | **退出** | 造一条哪怕代价很大的退路，死地就变围地 |

**最后一行的意义**：**只要有退路，死地就不是死地。** 所以"造退路"这件事，在任何地形下都是第一优先。

## 八、一句判断

**先认地，再定打不打，最后才想怎么打。**

**多数人一上来就想"怎么打"，而真正的问题是"这一仗该不该打"。**
