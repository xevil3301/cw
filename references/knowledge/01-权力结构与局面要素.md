# 01 · 权力结构与局面要素

## 一、权力不是属性，是位置

最常见的误判是把权力当成人的属性："他很强""我没底气"。这是错的。权力是**关系的产物**，具体说，是"A 需要 B 手里的东西，而 B 不那样需要 A"这个不对称。

所以同一个在 A 部门呼风唤雨的人，换个部门可能什么都不是——不是他变了，是依赖结构变了。**你的权力水平，等于别人对你的依赖减去你对别人的依赖。**

这带来一个操作推论：想改变局面，不必先变强。**改变依赖关系**往往更便宜——让对方需要你，或让自己不那么需要对方，两件事任一发生，权力天平就动了。

## 二、六种权力基底（French & Raven, 1959）

| 基底 | 机制 | 失效条件 |
|---|---|---|
| 奖赏权 | 你能给好处 | 好处不再稀缺，或承诺不兑现 |
| 强制权 | 你能造成损失 | 对方不怕，或你无法持续施压 |
| 合法权 | 位置赋予的"应该服从" | 规则被质疑，或对方不认这套规则 |
| 专家权 | 你懂他不懂 | 知识被普及，或你出错 |
| 参照权 | 他想成为你／认同你 | 认同破裂，或你人设崩 |
| **信息权** | 你知道他不知道的 | 信息失效、过期、被证伪 |

French & Raven 原模型是五种，信息权是后人补的第六种。**在当代组织里，信息权是性价比最高的**——不需要职位、不需要预算、不需要威胁，只需要你知道别人不知道的事，并且让人知道你知道。

注意每种都带失效条件。**权力基底的失效条件，就是对手的攻击面。** 这句话是整个 skill 的底层逻辑之一：你用什么方式获得影响力，你就暴露在什么方式的攻击下。

## 三、五力图：把局面变成一张可比的表

面对任何局面，逐项打分（1–10）：

1. **决策权**：谁签字、谁否决、谁能把议题拿上桌
2. **资源**：钱、人、时间、设备、审批口
3. **信息**：谁知道什么、谁知道谁知道
4. **关系**：谁能直接打电话给谁、谁欠谁人情
5. **时间**：谁更急、谁的窗口更短

打完分，只做一件事：**找出分值差距最大的那一项**。那一项就是当前局面的主轴，其余四项是配角。

绝大多数人失败，是因为在"资源"上跟人硬拼，而真正的差距在"时间"——对方比你急，你根本不用拼资源。

## 四、替代选项与退出成本

谈判理论里叫 BATNA（Best Alternative To a Negotiated Agreement，Fisher & Ury, 1981）。通俗说：**谈不成，你还有什么**。

三个判断：

- 你的 BATNA 越好，你越不需要赢这一局
- 对方的 BATNA 越好，你越不该逼他
- **双方都不知道对方 BATNA 时，信息就是全部战场**

退出成本是 BATNA 的另一面。**退出成本低的一方握定价权**——因为"不玩了"这个选项随时可用，而对方必须给你一个留下来的理由。

推论：让自己"随时能走"，比让自己"更强"，通常更有效。这也是为什么专业能力（可迁移）比职位（不可迁移）更值钱。

## 五、案例：三个结构手术

### 案例 1 · 杯酒释兵权（961 年，赵匡胤）

**局面**：赵匡胤陈桥兵变黄袍加身，靠的是禁军将领拥立。他坐上了皇位，但同样的机制可以再演一次——他自己就是先例。

**手段**：不杀、不贬、不查。设宴，席间说"你们部下要是也把黄袍披你们身上怎么办"，然后给地、给钱、给婚姻。原话是"出守大藩，择便好田宅市之，为子孙立永久之业"（白话：到大的州郡去做长官，挑好田好宅买下来，给子孙留一份永久的产业）。次日诸将称病请辞。

**出处补正**：这段对话的完整文本见于李焘《续资治通鉴长编》卷二建隆二年七月条，非《宋史·石守信传》原文；《宋史》本传记载较略。引用时以《长编》为准。

**结构变化**：把"兵权"从一个**不能交易**的东西（将死兵散）变成了一个**可以交易**的东西（权换富贵）。交易一旦成立，将领就从"潜在竞争者"变成"利益相关方"。

**可复用结论**：最干净的削权，是给对方一个比权力更划得来、且不需要权力的未来。**用利益换结构，不用暴力改结构。**

### 案例 2 · 推恩令（前 127 年，主父偃献策，汉武帝）

**局面**：汉初分封的诸侯国"连城数十，地方千里"，朝廷直接削藩会引发七国之乱那样的反弹（前 154 年已验证过一次）。

**手段**：不下令削地，反而下令"施恩"——诸侯王的封地，由所有儿子平分，不再只传嫡长子。

**结构变化**：这条命令表面上给了庶子们天大的好处，实际上让每个诸侯国自动分裂成若干小国。**几代之后，诸侯"大国不过十余城"，再无对抗中央的能力。**

**可复用结论**：最高级的结构手段，是让对手**自己执行你的意图**，并且心甘情愿。判据是：如果对方看穿了还想照做，那就是 A 级手段。

### 案例 3 · 屋大维的合法性重构（前 27 年）

**局面**：凯撒被刺（前 44 年），因为"称王"触碰了罗马共和的合法性红线。屋大维是凯撒的养子和继承人，天然背着同样的嫌疑。

**手段**：前 27 年，他在元老院**公开交还**全部权力，只请求保留"元首"（princeps，第一公民）称号与若干行省。元老院反而恳请他不要交还，并授予"奥古斯都"尊号。

**结构变化**：他不做独裁官（dictator，凯撒用过的头衔），而把实质权力装在共和制的语言外壳里。**权力没少，合法性成本降到了零。**

**可复用结论**：当名义与实质冲突时，改名义比改实质便宜。**别争头衔，争头衔底下的东西。**

## 六、多方依赖矩阵（三人以上必用）

五力图只有两列——它假设场上只有你和对手。**三人以上，五力图直接失真。**

### 为什么失真

- 你动 A，B 会反应
- B 的反应会改变 A 的下一步
- 而 C 可能谁的边都不站，只在等结果

**你算的是一次，现实是连续多轮。** 所以三方以上的局，第一个要问的不是"谁更强"，是"**谁先动**"。

### 矩阵怎么画

只画**关键的三到四列**，每格填依赖强度（高／中／低）：

```text
         我      对手A   第三方B   观望者C
我       —       低       中        无
对手A    高       —       高        无
第三方B  中       低       —         低
观望者C  无       无       低        —
```

**读法只两条**：

1. **依赖最少的那一格，就是定价者**——他不需要谁，所以他能定条件
2. **最先动的那一方，定义了局面**——不是最强的，是最快的

### 三类观望者（必须分清）

| 类型 | 特征 | 他怎么变成你的人 |
|---|---|---|
| **传话人** | 两边都说话，两边都不站 | 不要通过他传话；直接找另一头 |
| **等结果的人** | 谁赢跟谁 | 给他一个"现在表态不亏"的理由 |
| **依附者** | 已经站了，只是没公开 | 别逼他公开；逼了他会回去表忠心 |

**最容易犯的错**：把"传话人"当成"盟友"。传话人的价值是信息，不是票。

### 两条操作规则

1. **三方以上，不要一次动两个人。** 你动 A，B 会重新评估；你同时动 A 和 B，两个人会结盟。
2. **每动一步，重画一次矩阵。** 因为 C 的立场会随 A 和 B 的动作改变——这是"算一次"失效的根本原因。

## 七、局面建模卡
```text
【主轴】五力图里差距最大的一项：______
【依赖】我需要的 → 他有；他需要的 → 我有
【不对称】净差值：__（正数=我占优）
【BATNA】我的：______ 他的：______
【退出成本】我的：__  他的：__
【时间】我的窗口：__  他的窗口：__
【第一动作】改依赖 / 改时间 / 改信息 / 改议程？（四选一）
```

只填这七行，多数局面就清楚了。填不出来的那几格，就是你还需要侦察的地方。

## 七、常见错误

1. **把"他态度差"当权力信号**。态度是廉价的，算他与你的依赖差值。
2. **忽略时间维度**。时间是最被低估的权力来源，因为它不需要任何资源，只需要耐心。
3. **在错误的层打架**。在资源层输，却在信息层有绝对优势，却仍然拼资源。
4. **把一次胜利当结构改变**。赢一场不等于改结构，下次还要再打一遍。
