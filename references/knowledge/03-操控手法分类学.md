# 03 · 操控手法分类学

## 一、先划一条线：影响 vs 操控

两者用同一批心理机制，差别不在手法，在三个结构条件：

| 条件 | 影响 | 操控 |
|---|---|---|
| 意图透明 | 对方知道你希望他做什么 | 隐藏真实目的 |
| 选择保留 | 保留拒绝的现实可能 | 剥夺或惩罚拒绝 |
| 弱点使用 | 针对需求，不针对伤口 | 针对恐惧、羞耻、依赖 |

**判据（一句话版）**：把这招的完整机制解释给对方听之后，它是否还成立？
——还成立，是影响；立刻失效，是操控。

这条判据是 `dark-psychology-skills` 提出的，我认为它是这个领域里最有用的单条规则，直接抄进本 skill 的出厂检验。

**注意**：这不是道德分级，是**耐用性分级**。操控见光死，所以需要持续的信息控制来维持；影响可持续，因为不依赖隐瞒。选哪种，取决于这段关系还要重复博弈几次（见 10 篇）。

## 二、四条主轴

任何操控手法，都可以定位在四个维度上：

1. **信息轴**：他知道什么、不知道什么、以为知道什么
2. **情绪轴**：恐惧、羞耻、愧疚、希望、归属
3. **结构轴**：选项、时间、退出成本、见证人
4. **身份轴**：他把自己看成谁，他怕变成谁

**四轴同时被压缩到一个方向上时，人就失去判断力。** 这是所有高强度操控的共同结构。反过来，防御的方法是**把四轴拆开**——只要有一轴松动，压力就泄了。

## 三、手法清单（按主轴归类）

### 信息轴

| 手法 | 机制 | 识别信号 |
|---|---|---|
| **信息垄断** | 只让你看到一部分事实，你在残缺信息上做的判断必然利他 | 所有信息都经过同一个人、同一个渠道 |
| **信息过载** | 用大量细节淹没关键项 | 材料很多，但关键数字始终模糊 |
| **来源污染** | 提前散布关于某人/某方案的不利传闻 | "我听说……""大家都这么说" |
| **口径漂移** | 同一件事在不同场合给不同版本，事后否认 | 你开始怀疑自己的记忆（gaslighting 的雏形） |
| **假选项** | 给两个都指向同一结果的选项 | A 和 B 差别很大，但结果一样 |

### 情绪轴

| 手法 | 机制 | 识别信号 |
|---|---|---|
| **时间压迫** | 压缩决策时间，关闭理性核算 | "今天必须定" |
| **恩情账** | 把帮助记成债务，随时可提现 | 每次拒绝都被翻旧账 |
| **羞耻点打击** | 攻击身份而非行为 | "你这种人就是……" |
| **愧疚植入** | 让对方为你的情绪负责 | "你这样做我很失望" |
| **希望挂饵** | 给一个永远差一步的承诺 | 每次接近兑现就出现新条件 |

### 结构轴

| 手法 | 机制 | 识别信号 |
|---|---|---|
| **孤立** | 切断对方的外部信息源与支持者 | 你与朋友/家人的联系变少 |
| **移动球门** | 每次达标后提高标准 | 你永远"还差一点" |
| **沉没成本锁定** | 让投入不断累积，退出变贵 | "都已经投入这么多了" |
| **三角测量** | 引入第三方制造竞争与不安 | "别人可比你配合多了" |
| **合法性借用** | 用规则、流程、集体意志包装个人意图 | "这是规定""大家都同意" |

### 身份轴

| 手法 | 机制 | 识别信号 |
|---|---|---|
| **人设绑定** | 让你承诺一个身份，之后用一致性驱动行为 | "你不是最讲义气的人吗" |
| **恩主—门生结构** | 用提携制造等级，把平等关系变成上下关系 | 帮忙之后，称呼和姿态变了 |
| **敌人制造** | 用共同敌人绑定群体，内部异议被定义为背叛 | 质疑方案＝站到对面 |

## 四、古典对照：韩非子八奸的现代转译

《韩非子·八奸》写于公元前 3 世纪，是一份完整的**近身操控威胁模型**。它的价值在于：八术每一术都配了防术，攻防对称。

| 八奸 | 原义 | 现代对应 |
|---|---|---|
| **同床** | 走内宠路线，趁私密时刻提要求 | 走"身边人"路线：配偶、助理、密友 |
| **在旁** | 收买近侍，先意承旨 | 秘书、司机、群里的"传话人" |
| **父兄** | 结交继承人集团与大臣 | 押注接班人、押注下一任领导 |
| **养殃** | 纵容享乐、加重负担以乱其心 | 让决策者沉迷于次要事务，从中取利 |
| **民萌** | 散公财收民心，使朝野誉己 | 用公司资源做个人声望 |
| **流行** | 养辩士、造流行之辞，示利惧害 | 舆论造势、水军、内部"意见领袖" |
| **威强** | 聚亡命之徒，明言顺我者利、逆我者死 | 建立私人势力，形成人身依附 |
| **四方** | 借外部强权压内部 | 借外部客户/上级/资本压内部决策 |

**韩非子给的防术（原文要点）**：君主对内宠"娱其色而不行其谒"；对近侍"使其身必责其言"；对父兄大臣"听其言也必使以罚任于后"；对享乐"必令之有所出"；对施惠"必出于君，不使人臣私其德"；对议论"必实其能，察其过"；对勇力"军功无逾赏，邑斗无赦罪"；对诸侯"法则听之，不法则距之"。

**八条防术的共同结构**：**把"谁给的好处"和"谁做的决定"重新绑定到同一个主体上。** 一旦好处和决定分离，权力就漏了。

## 五、三个真实案例

### 案例 1 · 指鹿为马：服从性测试（前 207 年）

赵高献鹿称马，二世质疑，问群臣。沉默者、称马者留，称鹿者被"阴中诸言鹿者以法"。

**手法拆解**：这不是信息操控（没人真的相信鹿是马），是**公开表态机制**。一旦你在公开场合说过违心的话，你就把自己交出去了——因为承认错误等于自毁，继续维持等于共谋。**操控的目标不是让你相信，是让你无法回头。**

**防御**：任何要求你"当众表态"的场合，先问一句"这个表态会被记录吗、会被用来做什么"。

### 案例 2 · 埃姆斯电报：文本篡改（1870 年 7 月 13 日）

普鲁士国王威廉一世在埃姆斯温泉与法国大使贝内德蒂会面，婉拒了法国对西班牙王位继承的要求，随后发电报向俾斯麦通报经过。俾斯麦与毛奇、罗恩商议后，**删去了会面中温和的部分，只保留强硬措辞**，使电报读起来像是双方互相侮辱。

俾斯麦后来在回忆录中写道，他要的就是"一个对法国而言像红布对公牛一样的挑衅"（ein rotes Tuch für den gallischen Stier）。7 月 19 日法国宣战。

**手法拆解**：原始事实完全真实，只是**删除了语境**。这是信息轴操控里最难识别的一种——因为它不造假，它只做减法。**你无法指证他说了假话，你只能说他不完整。**

**防御**：判断一条信息，除了"真假"，还要问"**缺了什么**"。原始记录、完整文本、时间顺序，这三样决定了删减版的杀伤力。

### 案例 3 · 权威借用与秘密文化：Theranos（2013–2018）

伊丽莎白·霍姆斯以"只抽一滴血就能完成两百多项检测"为核心叙事，董事会聚集了基辛格、舒尔茨、马蒂斯等前政要，媒体估值一度达 90 亿美元。公司内部实行极端保密，员工签署保密协议、部门间不得交流，技术验证被切割成互不相通的片段。2015 年《华尔街日报》记者约翰·卡雷鲁依据内部举报人调查报道，2018 年公司解散，2022 年霍姆斯被判定诈骗罪成立。

**手法拆解**：三轴同时压缩——**权威轴**（政要背书替代技术验证）、**信息轴**（保密协议切断交叉验证）、**身份轴**（"我在改变医疗"的使命叙事让质疑者变成阻碍进步的人）。

**防御**：当一个项目同时具备"权威背书强 + 技术细节不透明 + 质疑者被道德化"三个特征时，无论它看起来多好，都按高风险处理。

## 六、操控的四个阶段（用于提前识别）

1. **筛选**：找有需求、缺支持、信息渠道单一的人
2. **建信**：小恩惠、小共鸣、小承诺
3. **压缩**：时间、选项、见证人三样同时收紧
4. **固化**：公开表态、书面承诺、既成事实，使退出成本高于服从成本

**关键判断点在第 3 阶段**。前两阶段和正常交往无法区分；第 3 阶段一旦出现"时间紧、选项少、没人可商量"的三重压缩，直接按操控处理，不必等到第 4 阶段。

## 七、使用边界（工程约束，非道德）

本 skill 收录这些手法，用途是两个：**用**和**防**。但用的时候必须记住成本结构：

- **信息轴手法**：见光即死，需要持续维护，维护成本随时间上升
- **情绪轴手法**：短期有效，长期摧毁对方的判断力，等于毁掉一个可用的合作者
- **结构轴手法**：最耐用，因为不依赖隐瞒，对方看穿也未必能反抗
- **身份轴手法**：威力最大，反噬也最大，一旦身份破裂，关系不可修复

按这个顺序选：**结构 > 信息 > 情绪 > 身份**。这跟 Yukl 的实证结论一致——越靠近"施压"和"身份胁迫"的手段，长期收益越差。
