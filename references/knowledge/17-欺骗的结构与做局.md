# 17 · 欺骗的结构与做局

## 零、先分清：骗与局

多数人把这两件事混为一谈，结果只会用最脆的那种。

| | 骗 | 局 |
|---|---|---|
| 定义 | 让他相信假的事 | 让他在真信息里做出你希望的选择 |
| 见光后 | 立即失效，且你人格归零 | **仍然成立**——因为他当时的选择是理性的 |
| 依赖 | 持续的信息封锁 | 一次性的结构设计 |
| 成本 | 维护成本随时间上升 | 前期设计成本高，后期为零 |

**核心判断：骗是消耗品，局是资产。**

而真正的老手，甚至不需要说谎——**他只需要决定对方在什么顺序下看到哪些真话。**

---

## 一、欺骗的三层

沿用信息战的 L1–L5，但换成进攻视角：

| 层 | 手法 | 见光后 | 使用建议 |
|---|---|---|---|
| **D1 隐瞒** | 不给、晚给、只给一部分 | 部分失效 | 最安全，但效果有限 |
| **D2 误导** | 给真信息，引导错误结论 | **仍然成立** | **主战场** |
| **D3 伪造** | 造假文件、假身份、假数据 | 立即失效 | 只在必须时用一次 |

**为什么 D2 是主战场**：它不需要你撒谎，所以你没有"被拆穿"的风险；它只利用对方自己的推理习惯，所以**即使他事后复盘，也只能怪自己判断错**。

**判据**：一件事如果只能用 D3 做成，说明这个局设计得不好——**你缺的不是谎言，是让对方自己走到那个结论的路径。**

## 二、为什么谎话会被打折（Crawford-Sobel）

**理论**：Crawford & Sobel (1982) 的策略信息传递模型——当一个信息优势方（Sender）向劣势方（Receiver）传递**无成本信号**（cheap talk）时，理性的接收者会**系统性打折**。因为说话不需要代价，谁都可以说。

**推论（这一节是全篇的地基）**：

1. **无成本的承诺，一律被折价**。"我一定帮你"这句话的信用接近于零
2. **要让谎话可信，必须给它加成本**
3. **最高级的欺骗，是根本不需要谎话**

### 加成本的三种方式

| 方式 | 做法 | 效果 |
|---|---|---|
| **押注** | 把自己的利益和这个说法绑定（"如果不是这样，我这个月的奖金不要"） | 强。但你真的要承担 |
| **见证** | 在有第三方在场时说出 | 中。第三方越重要，效果越强 |
| **九真一假** | 先让他验证九件真事，第十件他不查了 | **最强，成本最低** |

**"九真一假"为什么有效**：它利用的是**验证成本**。人不会逐条核实每句话，只会抽查。你让他抽查到三次真的，他就停止抽查了。

**操作**：把关键的那一条假信息，夹在**七到九条可验证的真信息**中间，且真信息要分布在前后，不要集中在开头。

## 三、局的五个零件

一个能成立的局，必须五件齐全。缺一件，就会在某个环节崩。

### 零件一 · 饵（他要什么）

**来源**：`knowledge/13` 的收益函数——他最想要什么、最怕失去什么。

**设计要求**：

- 饵必须是**他主动想要的**，不能是你塞给他的。你塞的，他会怀疑
- 饵的价值要**略高于他的正常预期**，但不能高到不合理。高太多 → 他警惕；不高 → 他不来
- 饵最好是**他一直在找但找不到的**东西（一个机会、一个认可、一个渠道）

**判定**：如果他拿到饵之后的第一反应是"这么容易？"，说明饵给多了。**正确的反应应该是"终于等到了"。**

### 零件二 · 认知（他相信的版本）

**这一层决定他如何解释接下来发生的一切。**

**设计要求**：

- 给他一个**能自圆其说的解释框架**，让他把你希望的事解释成"自然发生的"
- 框架里必须包含**他自己的利益**——一个只对你有好处的解释，他不会信
- 留一个**他可以自己验证的点**（这一点必须是真的）

**操作**：不要说"这是好事"，要说"这对你意味着 X"，并让 X 是他自己算出来的。

### 零件三 · 通道（他必须走的路径）

**目的**：让他在整个过程中**只有一个合理选择**，而不是你逼他。

**设计要求**：

- 表面上给他多个选项，实际上**只有一个选项的代价是可接受的**
- 其他选项的代价，由**环境**造成，不由你造成（这是可否认的关键）
- 通道要**短**——每一步都增加他中途醒过来的概率

**"代价由环境造成"怎么做到**：

> 不说"你不能选 B"，而是让 B 的截止期先过、让 B 需要的那个人出差、让 B 的成本因为某个客观原因上涨。

**你不是在阻止他，你只是没有帮他解决障碍。**

### 零件四 · 代价（他的损失如何被锁定）

**没有锁定的局，只是建议。**

**四种锁定方式**：

| 方式 | 机制 | 可逆性 |
|---|---|---|
| **沉没成本** | 让他先投入时间/钱/声誉 | 中 |
| **公开承诺** | 让他在有见证的场合表态（C5） | 低 |
| **既成事实** | 让事情进行到无法回退 | 最低 |
| **关系绑定** | 让他为这个局得罪过别人 | 低 |

**关键**：**代价要在他的认知框架里被解释成"他自己的选择"**，否则他会觉得自己被骗，从而不计成本地报复。

### 零件五 · 收口（你怎么退出）

**这一格最多人漏掉，也是局和骗的分界线。**

**收口的三个要求**：

1. **你在局里的角色，事后必须能解释成中性或善意**
2. **他的损失，必须能归因到他自己或环境**
3. **你要留一条他能接受的说法**——给他一个不丢面子的解释，否则他会为了面子跟你死磕

**判定**：收口设计失败的标志是——**他损失了，但他知道是你做的**。这时候局就退化成骗，而且是质量最差的那种。

## 四、用评估数据设计局

`knowledge/14` 的试探结果，直接对应局的零件。**这是"评估"和"做局"之间的转换表。**

| 试探测到什么 | 用在哪个零件 | 具体怎么做 |
|---|---|---|
| **他最想要什么** | 饵 | 把饵做成他一直在找的东西的形状 |
| **他最怕失去什么** | 通道 | 让不走进通道的后果，等于他最怕的那件事 |
| **他的时间有多紧** | 通道 | 用他的截止期，不用你的。**急的人先动** |
| **他的信息渠道有几个** | 认知 | 渠道少 → 只控制那一个；渠道多 → 让各渠道给出一致但不完整的版本 |
| **他信谁** | 认知 | 让他信任的那个人"无意中"提供关键信息 |
| **他的归因风格** | 收口 | 习惯外归因的人 → 把损失归给环境；习惯内归因的人 → 让他觉得是自己判断失误 |
| **他贪婪吗** | 饵 | 贪婪 → 加大饵；谨慎 → 减小饵，拉长时间 |
| **他抗压吗** | 通道 | 抗压低 → 用时间压迫；抗压高 → 用选项结构 |
| **他独立性高吗** | 认知 | 独立性高 → 不要用群体压力，用他自己的逻辑推 |
| **他嘴严吗** | 整个局 | 嘴不严 → 他会传播，你要准备好版本一致；嘴严 → 可以让他知道更多 |

**核心转换原则**：

> **不要设计一个"骗他"的局，设计一个"他自己算完发现这是最优解"的局。**

因为前者需要他一直被骗，后者**他会自己说服自己**——甚至在你收手之后，他还会替你维护这个局，因为承认被骗比承受损失更痛。

## 五、六种局型

### 局型一 · 请君入瓮

**出处**：来俊臣问周兴"囚多不承，当为何法"，周兴答"取大瓮，以炭四周炙之，令囚入中，何事不承"。来俊臣即取瓮如法，曰"请兄入此瓮"。周兴叩头服罪。（《资治通鉴·唐纪》）

**结构**：**让他自己说出方法，然后把方法用在他身上。**

**现代用法**：

1. 问他"如果是你，你会怎么处理这件事"（他会给出他最熟悉的方式，也就是他最有信心、最不设防的方式）
2. 用他给的方法对付他
3. 他无法抗议——**因为方案是他自己提的**

**关键**：这招之所以无解，是因为**反对等于否认自己的专业判断**。

**话术**：

> "按你上次说的那个思路，我照着做了。你看是不是这个意思？"

### 局型二 · 欲擒故纵

**结构**：**先给自由，让他自己选进来。**

**为什么有效**：人对自己选的东西，维护意愿远高于被安排的东西（承诺一致）。**你逼他做，他会反抗；他自己选的，他会替你辩护。**

**操作**：

1. 摆出多个选项，其中一个是你想要的
2. 明确指出那个选项的**缺点**（这会让其他选项显得像是你推荐的，从而被他排除）
3. 让他自己选

**注意**：缺点是**真的**。假的缺点一旦被验证，整个局崩。

### 局型三 · 借刀

**结构**：**用第三方的力量，你不出现。**

**适用**：你直接出手会暴露意图，或你的力量不足以对抗。

**操作**：

1. 找到与对方有真实利益冲突的第三方
2. **不要教第三方怎么做**——只需要让他知道某些事实（这些事实必须真实）
3. 让第三方自己决定行动

**关键**：**你只提供信息，不提供方案。** 提供了方案，你就成了主谋。

**风险**：刀有可能转向你。**先确认第三方对你有依赖，或你不在他的目标列表上。**

### 局型四 · 连环

**结构**：**多步嵌套，每一步都为下一步创造条件。**

**例**：先用一个小请求测他的边界（试探），再用小恩惠建立互惠（C3），再用一次公开确认固化（C5），最后用既成事实收口。

**设计要求**：

- 每一步单独看都是正常的、可解释的
- 只有连起来看才是局
- **每一步的失败都要能中止**，不能一步崩全盘

**这是最难被识别的局型**，因为它不依赖任何单点欺骗。

### 局型五 · 钓鱼

**结构**：**用小利引大鱼，先让他赢一次。**

**操作**：

1. 第一次交易，让他明显占便宜（甚至可以让他觉得你傻）
2. 第二次，恢复正常
3. 第三次，你的条件

**为什么有效**：第一次的"赢"会建立两个东西——他对你的**低估**，和他对这段关系的**投入**。两者都让你在第三次拥有定价权。

**关键**：第一次的损失必须**在你可承受范围内**，且第三次的收益必须**大于第一次的损失**。否则这不是局，是亏本。

### 局型六 · 反间

**结构**：**让他相信的假情报，来自他自己的人。**

**详见 `knowledge/18-用间与反间.md`。**

**这是所有局型里成本最低、效果最好的**——因为人对自己人给的信息，几乎不打折。

---

### 局型七 · 造势盘（示范型）

**这是"请君入瓮"的资金版**：不需要他开口，只需要他**看见**。

**结构五步**：

| 步 | 动作 | 关键 |
|---|---|---|
| **1 造势** | 让身边人先"赚到" | 第一层必须是**熟人**，你说他不信，第三个人说他才信 |
| **2 示范** | 让他看见别人的到账（截图、短信、饭桌上第三个人说"我真提出来了"） | 必须**可验证**，且**不由你提供**——你只负责在场 |
| **3 通道** | 只在指定入口交易 | 入口看起来像真的；他有别的选择，但那些"更麻烦" |
| **4 加码** | 给他尝到甜头，再加 | **买没有门槛，卖有门槛**：审核期、手续费、单日限额、大额预约 |
| **5 收手** | 在付不起之前走 | 判据见下 |

**提现摩擦是整个盘的技术核心。** 它同时做三件事：给增长争取时间、给你自己留撤退窗口、把"提不出来"解释成"流程问题"而不是"被骗"。

**收手判据（写死，不许凭感觉）**：

```text
新增进场的钱  <  要付给前面人的利息
→ 停。不是"赚够了再走"，是"撑不住之前走"。
```

**绝大多数盘不是被查掉的，是自己付不起息才崩的。**

**为什么有效**：他不是被说服的。**人是被"看见别人赚到"说服的，不是被道理说服的。** 而看见的东西，他事后无法否认——他会认为那是自己的观察。

**失效条件**：

| 条件 | 后果 |
|---|---|
| 有人集中提现 | 现金流断，盘立刻露 |
| 核心节点反水（第一层熟人发现被骗） | 整条信任链倒转，且他知道你是谁 |
| 增长停滞 | 付息压力直接落到你身上 |
| 外部介入（监管、平台、媒体） | 通道被封，钱进不来也出不去 |

**代价**：**这是全包法律暴露面最高的一种**——诈骗、非法集资、伪造金融票证同类。10 篇那张表的五项里，这一型的"法律暴露"和"报复概率"同时顶格。**它只适合一次性，且你已经不打算再用同一个身份。**

## 六、让谎话可信的五个技术

如果必须说谎（D3），这五个技术决定它能活多久。

### 1. 九真一假

七到九条可验证的真话包围一条假话。**真话要分布在前后，不要集中。**

### 2. 主动暴露一个无关紧要的缺点

> "这个方案有个问题，第三阶段的排期会比较紧。"

**主动承认小问题，会让你在其他地方的信用上升。** 这是最便宜的可信度投资。

### 3. 让他"自己发现"

**你希望他相信的事，不要说出来——制造条件让他自己推出来。**

自己推出的结论，抵抗外力修正的能力最强（这是确认偏误的反向利用）。

**操作**：给他两三条事实，让他自己连起来。**你只提供材料，不提供结论。**

### 4. 用他的逻辑，推你的结论

先说他的立场，再说"按这个逻辑往下推"，最后得出你要的结论。

**他无法反驳**，因为反驳等于否认自己的前提。

### 5. 可验证的承诺做抵押

> "如果这个月做不到，我按合同赔 5%。"

**这是最贵的一种，也是最有效的一种。** 用了就必须兑现——**一次不兑现，你所有的承诺都归零，而且是永久性的。**

## 七、局的三条铁律

### 铁律一 · 让他做的选择，对他不能是全输

**全输的局一定会被报复**，因为人可以为了一口气不计成本。

**正确的局**：他损失了，但他也得到了一些东西（哪怕不成比例）。**这让他有台阶，也让你安全。**

### 铁律二 · 局必须能拆

**设计的时候就要想好：如果中途要停，怎么停。**

不能拆的局，等于把自己也锁在里面——**对方一旦发现，你连退出的选项都没有。**

### 铁律三 · 收口在对方还能接受的时候

**贪最后一口，是绝大多数局崩掉的原因。**

对方已经开始怀疑，你却还想再拿一点——**这一口会让他从"我判断失误"变成"我被耍了"，而这两种认知对应的报复强度差十倍。**

## 八、反做局：你怎么知道自己进了局

七个信号：

| 信号 | 含义 |
|---|---|
| 一切都太顺 | 阻力被人为清除了 |
| 有人替你把障碍解决了 | 他在设计你的路径 |
| 你只有一个"合理"选项 | 通道已经建好 |
| 对方主动暴露小缺点 | 可能在建立可信度 |
| 消息来源恰好都是同一个人 | 认知在被控制 |
| 你被鼓励"自己决定" | 欲擒故纵 |
| 你已经投入很多，退出很贵 | 沉没成本锁定 |

**拆法**：

1. **强制引入第二个选项**（哪怕代价高）——打断通道
2. **倒推时间线**（谁在什么时候做了什么，谁受益）
3. **问"如果这是局，收口在哪"**——找到对方的退出点，你就知道他想拿什么
4. **故意做一次不符合预期的动作**——看谁的反应异常

---

## 九、一句判断

**最好的局，是对方事后复盘，仍然觉得当时那样选是对的。**

这不是因为他笨，是因为**你在他的理性范围内，把其他选项都变贵了**。

**骗是让他错，局是让他对——只是对你不亏。**
