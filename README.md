你有没有过这种时候。

明明是你被占了便宜，但你说不出哪里不对。等你反应过来，事情已经过去了，你只能在心里演一遍我当时应该这么说。

或者更糟的，你知道该反击，但你不敢。因为你不确定这一仗打不打得赢，也不知道打完还剩什么。

楚乌就是干这个的。

你把一个具体的局面丢给它，它给你三样东西。一句判断，几步今天就能做的动作，一句能直接发出去的话。

不是「你要学会沟通」这种话。是「这份材料别写控告写情况反映，走挂号信，实名，结尾加一句如有不实本人担责」。

## 它凭什么敢这么答

问得好。

这套东西底下压着三类材料，不是凭空长出来的。

一类是学术实证。《影响力》里那七条原则背后的原始实验。Schelling 讲承诺和威胁的《冲突的战略》。Axelrod 用计算机竞赛跑了几十种策略，最后发现赢的那个既不最狠也不最善，是最可预测的。Kahneman 和 Tversky 的锚定与框架。Crawford 和 Sobel 那个被引用七千次的 cheap talk 模型，它解释了为什么你说了真话别人也不信。Mintzberg 归纳的十三种组织政治游戏。还有 Kipnis 那套影响策略量表，以及后来 Yukl 做的效应排序，那条结论挺反直觉的，施压最无效，还持续拉低关系质量。

一类是古典文本。《孙子兵法》的九地，散地不宜战，轻地不可停，重地就地取利，围地找缺口，死地才拼命。《韩非子》的八奸，八种近身操控，每术都配了一条防术。《战国策》里说客的原话。《资治通鉴》的编年案例。《君主论》。《三十六计》。还有两本冷门的，《骗经》是明万历年间的骗术专著，八十多则骗局，每则后面标了受害者栽在哪个弱点上。《间书》是清代第一本间谍术专书。这些都在公有领域，我能查到原文，不是二手转述。

一类是真实案例。安然的表外负债怎么崩的。水门事件里掩盖的成本为什么高于原罪。Theranos 借了那么多政要的权威，崩塌时全部变成负资产。麦道夫的受害者为什么反过来替他说好话。斯德哥尔摩那六天。王莽怎么靠伪造符命受禅。司马懿在洛水边发的那个誓，和他背誓之后两百年的代价。

每一篇 references 后面都标了来源和证据级别，哪句是实验结论，哪句是史料原话，哪句只是推论，分得清楚。畅销书只用来提供词汇，不用来提供事实。

## 它怎么用

带着场景来就行。

不用先想清楚自己要什么，它会先问你三句。因为你要的和你说的经常不是一回事。有人说我要让他付出代价，问到第三句才发现，他其实想让这事赶紧过去。

问完，它先告诉你这个局该不该打。有的局看着憋屈，其实是散地，不该打。有的局看着没戏，但你手里有张牌自己没发现。

然后给你力度，一到五档。四档以上要过闸，过的不是你有没有理，是他反扑的时候你扛不扛得住。家庭关系里反扑常常是断供，平台那边是封店，这两种扛不住的时候，它不会让你硬上。

再往后就是话术了。每一句都过了五道自检，问的是顺序对不对，有没有条件式承诺，有没有道德表演，主语是谁，这话到底说给谁听。

## 它不干什么

不做心理治疗。长期焦虑、抑郁、创伤，找专业的人。

不给个案法律意见。它只能告诉你这类事通常看哪三点，该先固定什么证据，定性必须找律师。

不保证你赢。

四种情况它会直接说不行。涉及人身安全，涉及违法，目标跟手段彻底矛盾，或者你其实想要的是不付任何代价而不是某个结果。

它也会说，这个局现在没有进攻解。这不是敷衍。有些局的解不在怎么打，在怎么让自己先具备打的资格。

## 装上

```bash
cp -r cw ~/.agents/skills/cw
```

Windows。

```powershell
Copy-Item -Recurse .\cw "$env:USERPROFILE\.agents\skills\cw"
```

装完技能列表里会出现 `cw`。触发词，局面、谈判、被操控、话术、以弱胜强、被占便宜。

只吃单个 SKILL.md 的工具，直接投喂主文件就行，references 当按需检索的上下文。

## 一句实话

这东西没有实地验证过。

所有测试都是模拟场景加外部评委盲测，没有一个真实用户用它做完决定然后回来告诉我结果。

它擅长把一团乱麻拆成能判断的要素，把动作写到能做，把代价标到人头上。它不擅长给你勇气。一个不敢拒绝的人拿到十句完美话术，还是不敢发。

所以它最大的价值可能不是帮你赢。是让你在动手之前，先知道自己站在哪，该用多大力，代价落在谁身上。

这三件事想清楚了，多数局你自己就能解。

---

**楚乌**是乌鸦的古称。《说文》说，雅，楚乌也。《广雅》说，纯黑反哺者，谓之乌。

报丧的是它，反哺的也是它。凶名在外，孝行在内。
