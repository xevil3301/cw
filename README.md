# 楚乌 · cw

<p align="center">
  <img src="assets/logo.png" width="220" alt="cw">
</p>

**一个「带场景来、拿方案走」的工具。** 不是陪伴型助手，不做实时观察，不追踪你的生活。

> **楚乌**是乌鸦的古称——《说文》「雅，楚乌也」；《广雅》「纯黑反哺者，谓之乌」。
> **报丧的是它，反哺的也是它。凶名在外，孝行在内。**

你把一个具体局面丢进来，它给你一个判断、几个动作、一句能直接发出去的话。用着不对，回来改。

---

## 它是什么，不是什么

| 是 | 不是 |
|---|---|
| 一次性交付：一个场景 → 一份方案 | 长期陪伴：不追踪你的状态、不记你的生活 |
| 方案可迭代：用着不对就回来改 | 只给建议：不给「你一定能行」这类话 |
| 会说不：不合理的诉求，给算术不给方法 | 有求必应：做不到的事，直说做不到 |
| 会算代价：每一步标清「代价落在谁身上」 | 帮你想借口：不替你的选择找理由 |

**一句话**：**它负责把局面拆清楚、把动作写具体；决定和执行，是你的事。**

---

## 它解决什么

普通对话模型面对"老板这样对我怎么办""这个局我能不能打""我被拿捏了"这类问题，通常给情绪安慰和通用道理。本 skill 换一套做法：

- **先问诊**：你说的问题，往往不是你真正的诉求（复位／补偿／报复／面子／安全），先问三句再给方案
- **先认地**：九地判定（散地不宜战、轻地不可停、重地就地取利、围地找缺口、死地才拼命）——**决定该不该打，比决定怎么打更早**
- **定力度**：五个档位，四档分两种（对等反制／抬高成本），各有自己的闸门
- **给打法**：以弱胜强不是退和等，是换战场——六个必救、四个「我有你没有」、造牌七法、长跑三指标
- **标代价**：每份方案必须写「代价落在谁身上」，有人在替你承担时，沉默不是中性

## 怎么用（三种入口）

```text
① 我出事了          → 说清谁、争什么、你现在最怕什么
② 我要拿个结果      → 说清目标、对方是谁、你手上有几张牌
③ 我不知道该怎么办  → 直接讲事情经过，它会先问三句
```

**它第一轮可能只问你三个问题，不给方案。这不是敷衍——是因为问错了诉求，方案就是给别人准备的。**

**唯一例外**：你说"今天必须定"，它会先给一个动作，再补问诊。

---

## 用完之后

方案用着不对，直接把结果告诉它：

```text
"我按你说的做了，他的反应是……"     → 它会调整
"这一步我做不到，因为……"           → 它会降档
"这跟我实际情况不符，其实……"        → 它会重算
```

**这是这个 skill 唯一的「迭代」方式：不是它观察你，是你告诉它结果。**

## 使用边界（重要）

**三件事它不做：**

1. **不做心理治疗。** 长期焦虑、抑郁、创伤，找专业人士。
2. **不给个案法律意见。** 它只能告诉你"这类事通常看哪三点""该先固定什么证据"，定性必须找律师。
3. **不保证结果。** 它给的是"在已知条件下最合理的动作"，不是"一定赢"。

**四种情况它会直接说「不行」：**

- 涉及人身安全（家暴、跟踪、限制自由）→ 先走安全流程
- 涉及违法（做假账、伪造、代持、帮人洗钱）
- 目标与手段彻底矛盾，且不接受任何降档
- 你实际要的是"不付代价"，而不是"某个结果"

**这四句话比那 61 篇更值钱**——它们决定了这个工具会不会害人。

## 已知局限

- **没有实地验证。** 所有测试都是模拟场景 + 外部评委盲测，没有一个真实用户用它做完决定后回来反馈结果。
- **依赖你提供的信息。** 你没说的那一部分，往往是决定性的。
- **擅长分析，不擅长给你勇气。** 一个不敢拒绝的人拿到十句完美话术，还是不敢发。
